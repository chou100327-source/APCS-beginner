# APCS 初級 · Python 自學教材（詳細版）＋程式識讀補充

這是 [APCS 自學教材](https://github.com/chou100327-source/APCS) 的**初級專用版**：只保留初級題本的 7 個單元，並把每個單元擴寫得更詳細（逐步拆解表、追蹤表、更多範例與題目）。中級與進階延伸的內容已全部移除。

- 節奏：每個單元先讀觀念，再做練習頁＋實作題

> 官方「程式識讀」的檢測範圍比初級「程式實作」寬（還包含函式、遞迴、陣列與串列、佇列堆疊、排序搜尋），所以另外補上 `02-識讀補充/`。**只考實作的話不用讀；要考識讀就照 ★ 順序讀，時間不夠從最後面開始捨棄。**

## 內容

| 目錄 | 內容 |
|---|---|
| `01-初級/` | 輸入與輸出、資料型態與變數、算術運算、邏輯運算、位元運算、條件判斷、迴圈（7 單元） |
| `02-識讀補充/` | **程式識讀補充 8 單元，依重要程度排序**：★1 陣列與串列、★2 函式、★3 識讀題型技巧（追蹤・填空・除錯）、★4 時間複雜度、★5 遞迴、★6 排序、★7 搜尋、★8 堆疊與佇列 |
| `練習/` | 7 份「練習日」練習頁：先猜輸出、追蹤表、小程式、五分鐘小測驗，解答放在最下方 |
| `實作題/` | 11 題初級實作題（每題對應一個單元），參考解答放在檔案最下方 |
| `考前檢查表.md` | 考前每天掃一遍的自我檢查清單 |
| `website/` | 互動學習網站（教材閱讀、觀念題測驗、線上跑 Python 判題、動畫圖解、速查） |

每一節講義結構固定：**學完你要能做到 → 觀念講解（含逐步拆解表）→ Python 範例 → 經典應用 → 五分鐘小練習 → 常見錯誤**。

### 與原版相比增加了什麼

- 單元篇幅約為原版的 2–4 倍：每個運算子、每種寫法都有範例與「為什麼」
- 新增大量**追蹤表**（變數每一步怎麼變）與**手算拆解表**（長算式、二進位 AND/OR/XOR）
- 每單元小測驗從 3~4 題增加到 6~8 題；觀念題庫共 54 題，可依單元篩選
- 練習頁從 3 份增加到 7 份（每個單元一份）；實作題從 6 題增加到 11 題（全為初級）
- 修正了原版一處錯誤：Python 的 `&` 優先順序**高於**比較運算（`n & 1 == 0` 在 Python 裡等價於 `(n & 1) == 0`，與 C 相反），建議仍加括號

## 學習網站

六個分頁：首頁（學習計畫儀表板、進度環）、教材（含逐行走讀）、觀念題（隨機抽 15 題、選項打亂、錯題重練）、程式判題（**在瀏覽器裡直接跑 Python**）、動畫圖解、速查・筆記。

本機執行（需本地伺服器，因為要讀取上層的 `.md`）：

```bash
python3 serve.py
# 開 http://localhost:8000/website/
```

線上部署（Vercel）：直接匯入此資料夾即可，`vercel.json` 會把根目錄導向 `/website/`。詳見 `website/README.md`。

## 觀念題怎麼出（不會每次都一樣）

- **題庫 132 題**：原有 54 題＋追加 78 題；其中 49 題是「**仿歷屆題型**」（程式追蹤、選出正確敘述、位元／迴圈判斷…），依 APCS 歷屆考題的出題方式自己設計，所有附程式碼的題目答案都是真的把程式跑出來的。
- **每次 15 題**：10 題來自題庫（**優先出你還沒做過的**，做完一輪才會重新輪），5 題是**即時隨機生成**（`website/quizgen.js`，23 種題型，數字每次都不同，答案由程式依 Python 規則算出）。
- 錯的題（包含隨機生成的）會進「錯題重練」。
- 改了生成題型後，執行 `node tools/check_quizgen.js` 會把每個模板各生成數十題、真的用 Python 跑一遍核對答案。追加題庫由 `python3 tools/build_quiz_extra.py` 產生。
- 真正的歷屆試題有版權，不放在這個網站裡；請到 [APCS 官網](https://apcs.csie.ntnu.edu.tw/) 下載，或用 [ZeroJudge](https://zerojudge.tw/) 的 APCS 專區練習。

## 逐行走讀怎麼來的

教材裡每一段 Python 程式碼都能按「逐行走讀」。每一行會顯示：白話說明（帶入這次真實的數值）、**一步一步算**（照 Python 實際運算順序，每一步的結果與規則）、迴圈每一輪的變數變化、`if` 條件成立與否、實際印出的內容。這些是預先把程式碼真的跑過、記錄下來的（`website/trace.js`）。改了教材裡的程式碼之後，在專案根目錄執行 `python3 tools/build_trace.py` 重新產生。

## 判題怎麼運作

用 **Pyodide**（把 CPython 編成 WebAssembly）在你自己的瀏覽器裡執行 Python，程式碼**不會送到任何伺服器**。第一次使用要下載約 10MB 的執行環境（需要網路，之後瀏覽器會快取）；教材閱讀、讀書計畫、觀念題測驗則完全離線可用。

## 程式碼慣例

- 全部 Python 3，縮排一律 4 個空白。
- 讀輸入用 `int(input())` / `map(int, input().split())`；輸出**只印答案本身**，不印提示文字。
