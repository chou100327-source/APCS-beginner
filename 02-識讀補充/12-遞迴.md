## 一、什麼是遞迴？

函式**呼叫自己**，把大問題變成「一個小一點的同類問題」。

```python
def fact(n):
    if n <= 1:            # ① 終止條件（Base case）：最小的問題直接給答案
        return 1
    return n * fact(n - 1)    # ② 把 n 的問題縮小成 n-1

print(fact(5))            # 120
```

兩個要素缺一不可：

| 要素 | 作用 | 少了會怎樣 |
|---|---|---|
| 終止條件 | 讓遞迴停下來 | 無窮遞迴，`RecursionError` |
| 縮小規模 | 每次更接近終止條件 | 永遠到不了終點 |

## 二、追蹤 `fact(4)`：展開與回傳

```python
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

print(fact(4))      # 24
```

**往下展開（呼叫）**：

```
fact(4) = 4 * fact(3)
              fact(3) = 3 * fact(2)
                            fact(2) = 2 * fact(1)
                                          fact(1) = 1   ← 終止，開始回傳
```

**往回傳（返回）**：

| 呼叫 | 等待的算式 | 拿到結果後 |
|---|---|---|
| fact(1) | — | 回傳 1 |
| fact(2) | 2 × fact(1) | 2 × 1 = 2 |
| fact(3) | 3 × fact(2) | 3 × 2 = 6 |
| fact(4) | 4 × fact(3) | 4 × 6 = 24 |

> 每一層呼叫都有**自己的** `n`。fact(4) 停在「等 fact(3) 回來」，直到最底層算出答案才一層層往回乘。這就是**呼叫堆疊（call stack）**：最後被呼叫的，最先結束。

## 三、先印、後印：輸出順序不同

```python
def down(n):
    if n == 0:
        return
    print(n, end=" ")     # 先印，再遞迴
    down(n - 1)

def up(n):
    if n == 0:
        return
    up(n - 1)             # 先遞迴，再印
    print(n, end=" ")

down(3)
print()
up(3)
print()
```

輸出：

```
3 2 1
1 2 3
```

| 函式 | 順序 | 原因 |
|---|---|---|
| `down(3)` | 3 2 1 | 每層先 print 自己的 n，再往下 |
| `up(3)` | 1 2 3 | 每層先等更深的層做完，回來才 print |

追蹤 `up(3)`：`up(3)` 先呼叫 `up(2)` → `up(1)` → `up(0)` 直接返回；回到 `up(1)` 印 1；回到 `up(2)` 印 2；回到 `up(3)` 印 3。

## 四、常見遞迴題

### 1. 加總 1 到 n

```python
def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)

print(total(4))     # 10   4 + 3 + 2 + 1 + 0
```

### 2. 費氏數列

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(8)])   # [0, 1, 1, 2, 3, 5, 8, 13]
```

`fib(4)` 的展開樹：

```
fib(4)
├─ fib(3)
│   ├─ fib(2)
│   │   ├─ fib(1) = 1
│   │   └─ fib(0) = 0
│   └─ fib(1) = 1
└─ fib(2)
    ├─ fib(1) = 1
    └─ fib(0) = 0
```

`fib(4) = fib(3) + fib(2) = 2 + 1 = 3`。注意 `fib(2)`、`fib(1)` 被重複算了好幾次。

> **樸素費氏遞迴是 O(2ⁿ)**：重複計算太多，n = 40 就慢到不行。解法：**記憶化**（把算過的存起來）或改用迴圈。

```python
memo = {}
def fib2(n):
    if n <= 1:
        return n
    if n in memo:
        return memo[n]          # 算過了，直接拿
    memo[n] = fib2(n - 1) + fib2(n - 2)
    return memo[n]

print(fib2(30))                  # 832040
```

### 3. 最大公因數

```python
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)

print(gcd(48, 18))     # 6
```

追蹤：gcd(48,18) → gcd(18,12) → gcd(12,6) → gcd(6,0) → 回傳 6。

### 4. 次方

```python
def power(x, n):
    if n == 0:
        return 1
    return x * power(x, n - 1)

print(power(2, 5))     # 32
```

## 五、無窮遞迴

```python
def bad(n):
    return bad(n - 1)      # 沒有終止條件
# bad(3) 會一直呼叫下去，最後出現 RecursionError
```

另一種常見錯誤：有終止條件但**縮小錯了方向**，例如 `fact(n + 1)` 越來越遠離 0。

## 六、遞迴 vs 迴圈

```python
# 遞迴
def sum_rec(n):
    if n == 0:
        return 0
    return n + sum_rec(n - 1)

# 迴圈
def sum_loop(n):
    t = 0
    for i in range(1, n + 1):
        t += i
    return t

print(sum_rec(10), sum_loop(10))    # 55 55
```

| | 遞迴 | 迴圈 |
|---|---|---|
| 程式碼 | 簡潔（適合問題本身是遞迴定義） | 較長但直接 |
| 記憶體 | 每層都佔呼叫堆疊 | 只用幾個變數 |
| 速度 | 通常稍慢 | 通常較快 |
| 深度限制 | Python 預設約 1000 層 | 無 |

## 七、五分鐘小練習

```quiz
Q: 遞迴函式一定要有的兩個要素是？
* 終止條件與縮小規模
- 迴圈與條件
- 全域變數與區域變數
- print 與 return
E: 終止條件讓遞迴能停下來，縮小規模讓每次呼叫更接近終止條件。

Q: `def f(n): return 1 if n <= 1 else n * f(n - 1)`，`print(f(5))` 輸出？
* 120
- 24
- 5
- 15
E: f(5) = 5 × 4 × 3 × 2 × 1 = 120（5 的階乘）。

Q: `def up(n):` / `    if n == 0: return` / `    up(n - 1)` / `    print(n, end=" ")`，呼叫 `up(3)` 輸出？
* 1 2 3
- 3 2 1
- 3 3 3
- 0 1 2 3
E: 先遞迴到最深層，回來時才依序印 1、2、3。

Q: 把上一題的 print 移到 `up(n - 1)` 的前面，呼叫 `up(3)` 輸出？
* 3 2 1
- 1 2 3
- 3 3 3
- 1 1 1
E: 先印當層的 n，再往下遞迴，所以是 3 2 1。

Q: 費氏數列 fib(0)=0、fib(1)=1、fib(n)=fib(n-1)+fib(n-2)，fib(6) 是？
* 8
- 5
- 13
- 6
E: 數列 0, 1, 1, 2, 3, 5, 8：fib(6) = 8。

Q: 樸素的遞迴費氏 `fib(n)` 時間複雜度是？
* O(2ⁿ)
- O(n)
- O(n²)
- O(log n)
E: 每次呼叫展開成兩個子呼叫且大量重複計算，呈指數成長。

Q: `def g(n): return g(n - 1)` 沒有終止條件，會發生什麼事？
* 無窮遞迴，最後 RecursionError
- 回傳 0
- 回傳 None 並正常結束
- 印出 n
E: 永遠沒有函式能停下來，呼叫堆疊越疊越深，直到超過 Python 的深度限制出錯。

Q: 記憶化（memoization）的做法是？
* 把算過的結果存起來，下次直接用
- 把函式改寫成 lambda
- 把變數改成全域
- 增加遞迴深度限制
E: 這樣每個子問題只算一次，費氏遞迴就從指數降到 O(n)。
```

## 八、常見錯誤

- **忘了終止條件**或條件寫錯（`n == 1` 但傳入 0 就永遠到不了）。
- **沒有 `return` 遞迴結果**：寫成 `n * fact(n-1)` 卻忘了 `return`，會回傳 None。
- **把輸出順序弄反**：先印後遞迴與先遞迴後印，順序相反。
- **以為每層共用同一個 n**：每次呼叫都有自己的參數與區域變數。
- **用樸素遞迴算大的費氏數**：會慢到超時，要記憶化或改用迴圈。
