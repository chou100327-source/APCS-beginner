# 11 時間複雜度與效能分析（識讀補充 ★ 優先度 4）

> **為什麼排第四**：官方識讀題型裡有「**程式效能分析**」——問你「這段程式要跑幾次」「資料變 2 倍，時間變幾倍」「哪個寫法比較快」。它也是判斷「為什麼這樣寫會超時（TLE）」的依據。這個單元不難，抓到「數迴圈次數」的方法就能拿分。

> **本單元學完你要能做到**
> 1. 數出一段程式「最關鍵那一行」總共執行幾次
> 2. 用 O(1)、O(log n)、O(n)、O(n log n)、O(n²) 描述成長速度
> 3. 說出資料變大時，執行時間大約變成幾倍
> 4. 比較兩種寫法哪個效率較好，並說出原因

---

## 一、什麼是時間複雜度？

不是用「秒」，而是看**當資料量 n 變大時，執行步數怎麼成長**。因為不同電腦快慢不同，但「成長的速度」是固定的。

- 資料量 n：串列的長度、輸入的數字大小……
- 步數：最關鍵、執行最多次的那一行跑了幾次。

**Big-O 的化簡規則**：
1. 只留成長最快的那一項。
2. 去掉前面的常數係數。

例：步數是 `3n² + 5n + 2` → 化簡成 **O(n²)**。

---

## 二、常見的複雜度，從快到慢

| 記法 | 名稱 | 直覺 | n = 1000 時大約幾步 |
|---|---|---|---|
| O(1) | 常數 | 不管多大都一樣 | 1 |
| O(log n) | 對數 | 每次砍一半 | 10 |
| O(n) | 線性 | 一個迴圈走過全部 | 1,000 |
| O(n log n) | 線性對數 | 好的排序法 | 10,000 |
| O(n²) | 平方 | 雙層迴圈 | 1,000,000 |
| O(2ⁿ) | 指數 | 每個元素「選或不選」 | 天文數字 |

背順序：**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)**。

## 三、怎麼數迴圈次數

### 1. 單一迴圈：O(n)

```python
n = 6
count = 0
for i in range(n):
    count += 1
print(count)       # 6
```

`count += 1` 執行 n 次 → O(n)。

### 2. 兩個迴圈「前後排」：相加 → 仍是 O(n)

```python
n = 6
count = 0
for i in range(n):
    count += 1
for j in range(n):
    count += 1
print(count)       # 12
```

n + n = 2n，去掉係數 → O(n)。

### 3. 雙層迴圈「巢狀」：相乘 → O(n²)

```python
n = 6
count = 0
for i in range(n):
    for j in range(n):
        count += 1
print(count)       # 36
```

n × n = n² → O(n²)。

### 4. 內層次數依外層變：加總

```python
n = 6
count = 0
for i in range(n):
    for j in range(i):
        count += 1
print(count)       # 15
```

內層次數是 0+1+2+3+4+5 = 15 = n(n−1)/2，仍是 O(n²)。

### 5. 每次乘除：O(log n)

```python
n = 64
count = 0
while n > 1:
    n //= 2
    count += 1
print(count)       # 6
```

64 → 32 → 16 → 8 → 4 → 2 → 1，共砍 6 次 = log₂64。

> **判斷訣竅**：迴圈變數每次「**加減**」固定數 → 跑 O(n) 次；每次「**乘除**」固定倍數 → 跑 O(log n) 次。

### 6. 沒有迴圈：O(1)

```python
a = [5, 3, 8]
x = a[2] + a[0]      # 取值、加法，不管 a 多長都一樣快
print(x)             # 13
```

## 四、資料變大，時間變幾倍？

| 複雜度 | n 變成 2 倍 | n 變成 10 倍 |
|---|---|---|
| O(1) | 不變 | 不變 |
| O(log n) | 多一點點（約 +1 步） | 多約 3 步 |
| O(n) | 2 倍 | 10 倍 |
| O(n²) | **4 倍** | **100 倍** |
| O(n³) | 8 倍 | 1000 倍 |

> 「n 加倍，O(n²) 變 4 倍」是最常考的。

## 五、實際比較兩種寫法

**範例：判斷 `x` 有沒有在串列 `a` 裡**

```python
a = [4, 8, 15, 16, 23, 42]
x = 23
found = False
for v in a:
    if v == x:
        found = True
        break
print(found)         # True
```

線性搜尋，最差要看 n 個 → O(n)。（若串列已排序，可改用二分搜尋 O(log n)，見單元 14。）

**範例：1 加到 n**

| 寫法 | 步數 | 複雜度 |
|---|---|---|
| `for i in range(1, n+1): total += i` | n 次 | O(n) |
| `total = n * (n + 1) // 2` | 常數 | O(1) |

兩種結果相同，但第二種快很多：n = 10⁹ 時，第一種會超時。

```python
n = 100
t1 = 0
for i in range(1, n + 1):
    t1 += i
t2 = n * (n + 1) // 2
print(t1, t2)        # 5050 5050
```

## 六、APCS 的時限怎麼推

評測機大約 1 秒能跑 **10⁷ ~ 10⁸** 次簡單運算。看題目的資料上限 N：

| N 的上限 | 大約可以接受的複雜度 |
|---|---|
| ≤ 10 | 幾乎都行（甚至 O(n!)） |
| ≤ 1000 | O(n²) 可以 |
| ≤ 10⁵ | 要 O(n log n) 或 O(n) |
| ≤ 10⁷ | 要 O(n) 或更好 |
| ≤ 10⁹ | 要 O(log n) 或 O(1) |

## 七、五分鐘小練習

```quiz
Q: 一個演算法的步數是 `3n² + 5n + 2`，時間複雜度是？
* O(n²)
- O(3n²)
- O(n)
- O(n² + n)
E: Big-O 只留成長最快的項並去掉常數係數，所以是 O(n²)。

Q: 輸入規模 n 從 1000 變成 2000，O(n²) 的演算法時間大約變成幾倍？
* 4 倍
- 2 倍
- 8 倍
- 不變
E: 時間與 n² 成正比，n 變 2 倍時間就變 2² = 4 倍。

Q: 下列迴圈的時間複雜度是？`while n > 1:` / `    n = n // 2`
* O(log n)
- O(n)
- O(1)
- O(n²)
E: 每次把 n 砍半，約跑 log₂n 次。變數是乘除變化就是對數等級。

Q: 下列程式 `for i in range(n):` / `    for j in range(n):` / `        count += 1` 的時間複雜度是？
* O(n²)
- O(n)
- O(2n)
- O(log n)
E: 內外層相乘 n × n = n²。

Q: `for i in range(n): ...` 之後接另一個 `for j in range(n): ...`（兩個迴圈並排），總複雜度是？
* O(n)
- O(n²)
- O(2n²)
- O(log n)
E: 並排是相加：n + n = 2n，去掉係數仍是 O(n)。

Q: 下列複雜度由小到大排列，何者正確？
* O(1) < O(log n) < O(n) < O(n log n) < O(n²)
- O(1) < O(n) < O(log n) < O(n²) < O(n log n)
- O(log n) < O(1) < O(n) < O(n²) < O(n log n)
- O(n) < O(log n) < O(1) < O(n log n) < O(n²)
E: 常數最快，接著對數、線性、線性對數，平方最慢（這幾個之中）。

Q: 要算 1 + 2 + … + n，哪個寫法的複雜度最好？
* `n * (n + 1) // 2`
- `for i in range(1, n+1): total += i`
- 雙層迴圈每一對相加
- 用 `sum(range(1, n+1))`
E: 公式只算一次，是 O(1)；迴圈與 sum(range) 都是 O(n)。

Q: 某題 N 上限是 10⁵，下列哪種複雜度通常「會超時」？
* O(n²)
- O(n)
- O(n log n)
- O(log n)
E: 10⁵ 的平方是 10¹⁰，遠超過 1 秒能跑的 10⁷~10⁸ 次。
```

## 八、常見錯誤

- **把係數和低次項留著**：`O(3n² + n)` 要寫成 `O(n²)`。
- **並排迴圈誤算成相乘**：只有「巢狀」才相乘，並排是相加。
- **忽略內層次數會變**：`for j in range(i)` 總次數是 n(n−1)/2，不是 n²，但複雜度等級仍是 O(n²)。
- **把「變數加減」誤判成 log**：`i += 2` 仍是 O(n)；只有乘除才是 log。
- **只看程式碼行數**：複雜度看的是執行次數，一行 `for` 可能跑上億次。
