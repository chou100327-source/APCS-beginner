## 一、定義與呼叫

```python
def add(a, b):          # 定義：只是「登記」這個函式，此時不會執行裡面的內容
    s = a + b
    return s            # 把結果送回呼叫的地方

result = add(3, 4)      # 呼叫：這時才會執行函式裡面的程式
print(result)           # 7
```

流程拆解（呼叫 `add(3, 4)` 時）：

| 步驟 | 發生什麼事 |
|---|---|
| ① | 把 `3` 交給參數 `a`、`4` 交給參數 `b` |
| ② | 執行函式內容：`s = 3 + 4 = 7` |
| ③ | `return s` 把 `7` 送回呼叫處 |
| ④ | `result = 7`，函式的區域變數 `a`、`b`、`s` 全部消失 |

> **`def` 只定義、不執行。** 沒有被呼叫的函式，裡面的程式一行都不會跑。

## 二、參數與回傳值

```python
def square(x):
    return x * x

print(square(5))                 # 25
print(square(2) + square(3))     # 13   4 + 9

def greet(name, times):
    for _ in range(times):
        print("Hi,", name)

greet("Amy", 2)
```

`greet("Amy", 2)` 印出兩行：`Hi, Amy`、`Hi, Amy`。

### 預設參數與關鍵字參數

```python
def power(base, exp=2):          # exp 沒給時預設是 2
    return base ** exp

print(power(3))          # 9
print(power(3, 3))       # 27
print(power(exp=4, base=2))   # 16   用名字指定，順序可以換
```

### 回傳多個值

```python
def stats(nums):
    return min(nums), max(nums)     # 其實回傳的是一個 tuple

lo, hi = stats([4, 9, 2])
print(lo, hi)            # 2 9
print(stats([4, 9, 2]))  # (2, 9)
```

## 三、沒有 `return` 會得到 `None`

```python
def hello():
    print("hello")       # 只是印出來，沒有 return

x = hello()              # 印出 hello
print(x)                 # None
```

| 寫法 | 呼叫端拿到 |
|---|---|
| `return 7` | 7 |
| `return`（後面沒東西） | None |
| 完全沒有 return | None |

> **`print` 和 `return` 完全不一樣**：`print` 是把東西顯示在螢幕上；`return` 是把值交給呼叫的人。函式裡只有 `print`，呼叫端的變數會是 `None`。

`return` 一執行，函式**立刻結束**，後面的程式不會跑：

```python
def sign(n):
    if n > 0:
        return "正"
    if n < 0:
        return "負"
    return "零"

print(sign(5), sign(-2), sign(0))   # 正 負 零
```

## 四、區域變數與全域變數

函式**裡面**建立的變數，只在函式裡有效（區域變數）；函式**外面**建立的是全域變數。

```python
x = 10                 # 全域變數

def f():
    x = 20             # 這是一個新的區域變數 x，和外面的 x 無關
    print(x)           # 20

f()
print(x)               # 10   外面的 x 沒變
```

### 只讀取全域變數是可以的

```python
total = 100

def show():
    print(total)       # 只讀取，沒問題：100

show()
```

### 想「修改」全域變數要用 `global`

```python
count = 0

def inc():
    global count       # 宣告：下面的 count 指的是全域那個
    count += 1

inc()
inc()
print(count)           # 2
```

沒有 `global` 就 `count += 1` 會出錯（`UnboundLocalError`），因為 Python 以為你要建立區域變數 `count`，卻在建立前就拿來讀。

| 情況 | 結果 |
|---|---|
| 函式裡 `x = 值` | 建立區域變數，不影響外面 |
| 函式裡只讀 `x`（外面有 x） | 讀到全域的 |
| 函式裡要改全域的 x | 要先寫 `global x` |
| 函式結束 | 區域變數全部消失 |

## 五、串列傳進函式：會被改到

數字、字串傳進去是「複製值」，函式裡怎麼改都不影響外面；但**串列**傳進去，函式和外面共用同一個串列：

```python
def add_one(a):
    a.append(1)          # 直接修改了傳進來的串列

nums = [5]
add_one(nums)
print(nums)              # [5, 1]   外面的串列也變了

def bump(n):
    n = n + 1            # 只是改了區域的 n
    return n

v = 5
bump(v)
print(v)                 # 5   外面的 v 沒變
```

> 原因：`a` 和 `nums` 是同一個串列的兩個名字（見單元 08 的 `b = a`）。

## 六、函式呼叫函式、追蹤順序

```python
def f(x):
    return x + 1

def g(x):
    return f(x) * 2

print(g(3))     # 8
```

追蹤：`g(3)` → 先算 `f(3)` = 4 → `4 * 2` = 8。

追蹤時畫表，一次呼叫一欄：

| 呼叫 | 參數 | 算什麼 | 回傳 |
|---|---|---|---|
| `g(3)` | x = 3 | `f(3) * 2` | 8 |
| `f(3)`（被 g 呼叫） | x = 3 | `3 + 1` | 4 |

## 七、經典範例

```python
def is_even(n):
    return n % 2 == 0

def count_even(nums):
    c = 0
    for x in nums:
        if is_even(x):
            c += 1
    return c

print(count_even([1, 2, 3, 4, 6]))    # 3
```

```python
def gcd(a, b):                # 最大公因數
    while b != 0:
        a, b = b, a % b
    return a

print(gcd(48, 18))            # 6
```

## 八、五分鐘小練習

```quiz

* 14
- 7
- 24
- 10

Q: `def hello(): print("hi")`，`x = hello()` 之後 `print(x)` 輸出？
* None
- hi
- 0
- 會噴錯
E: 函式沒有 return 就回傳 None。hello() 呼叫時會先印出 hi，之後 print(x) 才印出 None。

* 10
- 20
- 30
- 會噴錯
E: 函式裡的 x = 20 建立了新的區域變數，不會動到全域的 x。

Q: 函式裡想修改全域變數 count（例如 count += 1），必須怎麼寫？
* 在函式裡先寫 `global count`
- 在函式外寫 `local count`
- 把 count 寫成大寫
- 不用任何宣告
E: 沒有 global，Python 會把 count 當成區域變數，造成 UnboundLocalError。

Q: `def add_one(a): a.append(1)`，`nums = [5]`、`add_one(nums)` 之後 nums 是？
* [5, 1]
- [5]
- [1]
- None
E: 串列傳進函式是共用同一個，函式裡的修改會影響外面。

Q: `def stats(n): return min(n), max(n)`，`print(stats([4, 9, 2]))` 輸出？
* (2, 9)
- [2, 9]
- 2 9
- None
E: return 用逗號隔開多個值，實際回傳一個 tuple，印出來有小括號。

Q: 函式裡 `return` 執行之後，後面的程式會怎樣？
* 不會執行，函式立刻結束
- 照樣繼續執行
- 只有下一行會執行
- 會噴錯
E: return 會讓函式立刻結束並把值送回呼叫端。

Q: 下列說法何者正確？
* 只有「定義」函式、沒有「呼叫」，函式裡的程式不會執行
- def 那一行會立刻執行函式裡的內容
- 函式一定要有參數
- 函式的區域變數在函式結束後仍可從外面讀取
```

## 九、常見錯誤

- **只 `print` 沒 `return`**：呼叫端拿到 `None`，後續運算會 `TypeError`。
- **忘記呼叫**：只寫 `add` 而不是 `add(3, 4)`，什麼都不會發生。
- **在函式裡修改全域變數卻沒寫 `global`**：`UnboundLocalError`。
- **參數個數不對**：`add(3)` 少一個參數會 `TypeError`。
- **以為函式裡的變數出了函式還在**：區域變數離開函式就消失，要用 `return` 帶出來。
- **傳串列進函式時以為是複製**：函式裡改了串列，外面也跟著改；不想被改就先 `a[:]` 複製。
- **`return` 寫在迴圈裡太早**：`for` 裡面的 `return` 第一輪就結束整個函式。
