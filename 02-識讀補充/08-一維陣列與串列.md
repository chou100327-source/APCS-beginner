## 一、串列是什麼？

串列就是**一排有編號的格子**，每一格放一個值，編號（索引，index）**從 0 開始**。

```python
a = [10, 20, 30, 40, 50]
print(a)          # [10, 20, 30, 40, 50]
print(len(a))     # 5      有幾個元素
print(a[0])       # 10     第一個
print(a[4])       # 50     最後一個
print(a[-1])      # 50     負索引：-1 是最後一個
print(a[-2])      # 40     倒數第二個
```

| 索引 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 值 | 10 | 20 | 30 | 40 | 50 |
| 負索引 | -5 | -4 | -3 | -2 | -1 |

> **最後一個索引是 `len(a) - 1`，不是 `len(a)`。** 取 `a[5]` 會 `IndexError`（超出範圍）。

串列可以放不同型態，也可以是空的：

```python
mixed = [1, "two", 3.0, True]
empty = []
print(len(mixed), len(empty))   # 4 0
```

## 二、修改單一元素

串列**可以修改**（和字串不同）：

```python
a = [10, 20, 30]
a[1] = 99
print(a)          # [10, 99, 30]
a[-1] += 5
print(a)          # [10, 99, 35]
```

## 三、切片 `a[start:stop:step]`

切片取出「一段」，**含頭不含尾**（和 `range` 一樣），結果是**新的串列**。

```python
a = [0, 1, 2, 3, 4, 5, 6, 7]
print(a[2:5])      # [2, 3, 4]        索引 2、3、4
print(a[:3])       # [0, 1, 2]        開頭省略 = 從 0 開始
print(a[5:])       # [5, 6, 7]        結尾省略 = 到最後
print(a[-3:])      # [5, 6, 7]        最後三個
print(a[::2])      # [0, 2, 4, 6]     每隔一個
print(a[1::3])     # [1, 4, 7]        從 1 開始每次 +3
print(a[::-1])     # [7, 6, 5, 4, 3, 2, 1, 0]   反轉
print(a[5:2:-1])   # [5, 4, 3]        倒著取
print(a[2:100])    # [2, 3, 4, 5, 6, 7]  超過範圍不會出錯
```

| 寫法 | 意思 |
|---|---|
| `a[i:j]` | 索引 i 到 j-1，共 `j - i` 個 |
| `a[:j]` | 前 j 個 |
| `a[i:]` | 從 i 到最後 |
| `a[::-1]` | 整個反轉 |
| `a[::k]` | 每隔 k 個取一個 |

> 切片不會修改原本的串列，會產生一個新的。

## 四、增加、刪除、排序

```python
a = [3, 1, 2]
a.append(9)        # 尾端加一個
print(a)           # [3, 1, 2, 9]
a.insert(1, 7)     # 在索引 1 的位置插入 7（後面的往後移）
print(a)           # [3, 7, 1, 2, 9]
x = a.pop()        # 拿走最後一個，並回傳它
print(x, a)        # 9 [3, 7, 1, 2]
y = a.pop(0)       # 拿走索引 0 的那個
print(y, a)        # 3 [7, 1, 2]
a.remove(1)        # 移除「值」為 1 的第一個
print(a)           # [7, 2]
del a[0]           # 刪除索引 0
print(a)           # [2]
```

| 操作 | 作用 | 回傳 |
|---|---|---|
| `a.append(x)` | 尾端加 x | None |
| `a.insert(i, x)` | 在位置 i 插入 x | None |
| `a.pop()` / `a.pop(i)` | 拿走最後一個／第 i 個 | 被拿走的值 |
| `a.remove(x)` | 移除第一個等於 x 的 | None |
| `del a[i]` | 刪除第 i 個 | — |
| `a.extend(b)` | 把 b 的元素全加到尾端 | None |
| `a.sort()` | **原地**由小到大排序 | **None** |
| `sorted(a)` | 回傳排好的**新**串列 | 新串列 |
| `a.reverse()` | 原地反轉 | None |

```python
a = [3, 1, 2]
print(sorted(a), a)    # [1, 2, 3] [3, 1, 2]   sorted 不改原本的
a.sort()
print(a)               # [1, 2, 3]
a.sort(reverse=True)
print(a)               # [3, 2, 1]
b = a.sort()
print(b)               # None   ← 陷阱：sort() 回傳 None
```

> **經典陷阱**：`a = a.sort()` 會讓 `a` 變成 `None`。排序要嘛 `a.sort()`，要嘛 `a = sorted(a)`。

## 五、串列的運算與查詢

```python
a = [1, 2, 3]
b = [4, 5]
print(a + b)         # [1, 2, 3, 4, 5]   接起來
print(a * 2)         # [1, 2, 3, 1, 2, 3]  重複
print(2 in a)        # True
print(9 in a)        # False
print([1, 2, 2, 3].count(2))   # 2    出現幾次
print([5, 6, 7].index(7))      # 2    第一次出現的索引
print(max(a), min(a), sum(a))  # 3 1 6
```

## 六、走訪串列

```python
a = [4, 8, 15]
for x in a:                       # 方法 1：直接拿元素
    print(x, end=" ")             # 4 8 15
print()
for i in range(len(a)):           # 方法 2：用索引（要改元素、要用到位置時）
    print(i, a[i])
for i, x in enumerate(a):         # 方法 3：同時拿索引與元素
    print(i, x)
```

輸出（方法 2 或 3）：`0 4`、`1 8`、`2 15`。

> 要**修改**元素時用索引：`for x in a: x = x * 2` 改不了 `a`（x 只是複製出來的值）；要寫 `a[i] = a[i] * 2`。

### 常用模板

```python
nums = [4, 9, 2, 7]
total = 0
for x in nums:
    total += x
print(total)            # 22   加總

best = nums[0]
for x in nums[1:]:
    if x > best:
        best = x
print(best)             # 9    找最大

count = 0
for x in nums:
    if x % 2 == 0:
        count += 1
print(count)            # 2    偶數有幾個

rev = []
for x in nums:
    rev.insert(0, x)    # 每次插到最前面
print(rev)              # [7, 2, 9, 4]
```

## 七、串列生成式（一行建立串列）

```python
sq = [i * i for i in range(1, 6)]
print(sq)                          # [1, 4, 9, 16, 25]
ev = [x for x in range(10) if x % 2 == 0]
print(ev)                          # [0, 2, 4, 6, 8]
```

格式：`[運算式 for 變數 in 可迭代的東西 if 條件]`，`if` 可省略。

## 八、最容易考的陷阱：`b = a` 不是複製

```python
a = [1, 2, 3]
b = a            # b 和 a 是「同一個串列」的兩個名字
b[0] = 99
print(a)         # [99, 2, 3]   ← a 也變了！
c = a[:]         # 真正的複製（切片產生新串列）
c[1] = 77
print(a, c)      # [99, 2, 3] [99, 77, 3]
d = a.copy()     # 另一種複製寫法
```

| 寫法 | 結果 |
|---|---|
| `b = a` | 同一個串列，改 b 就是改 a |
| `b = a[:]` 或 `a.copy()` | 新串列，互不影響 |

## 九、二維串列（簡述）

```python
r, c = 2, 3
grid = [[0] * c for _ in range(r)]     # 正確：每一列都是獨立的串列
grid[0][1] = 5
print(grid)       # [[0, 5, 0], [0, 0, 0]]

bad = [[0] * c] * r                    # 錯誤：兩列是同一個串列！
bad[0][1] = 5
print(bad)        # [[0, 5, 0], [0, 5, 0]]
print(grid[1][2], len(grid), len(grid[0]))   # 0 2 3
```

`grid[i][j]` 是第 i 列第 j 行；`len(grid)` 是列數、`len(grid[0])` 是行數。

## 十、五分鐘小練習

```quiz
Q: `a = [10, 20, 30, 40, 50]`，`print(a[1:4])` 輸出？
* [20, 30, 40]
- [10, 20, 30, 40]
- [20, 30, 40, 50]
- [20, 30]
E: 切片含頭不含尾：索引 1、2、3 對應 20、30、40。

Q: `a = [3, 1, 2]`，執行 `a = a.sort()` 之後 `print(a)` 輸出？
* None
- [1, 2, 3]
- [3, 1, 2]
- 會噴錯
E: sort() 是原地排序，回傳 None；把 None 指派回 a，a 就成了 None。

Q: `a = [1, 2, 3]`、`b = a`、`b[0] = 9`，之後 `print(a)` 輸出？
* [9, 2, 3]
- [1, 2, 3]
- [9, 9, 9]
- 會噴錯
E: b = a 沒有複製，a 與 b 是同一個串列的兩個名字。要真正複製請用 a[:] 或 a.copy()。

Q: `a = [5, 6, 7, 8]`，`print(a[-1], a[-3])` 輸出？
* 8 6
- 5 7
- 8 7
- 7 6
E: 負索引從尾巴倒數：-1 是最後一個 8，-3 是倒數第三個 6。

Q: `a = [0, 1, 2, 3, 4, 5]`，`print(a[::-2])` 輸出？
* [5, 3, 1]
- [0, 2, 4]
- [5, 4, 3]
- [4, 2, 0]
E: step 為 -2 表示從最後一個開始往前每隔一個取：5、3、1。

Q: 想建立 3 列 4 行、全為 0 的二維串列，哪個寫法正確？
* `[[0] * 4 for _ in range(3)]`
- `[[0] * 4] * 3`
- `[0] * 12`
- `[[0] * 3] * 4`
E: 用生成式讓每一列都是獨立的串列。`[[0]*4]*3` 的三列是同一個串列，改一格會三列一起變。

Q: `a = [4, 9, 2]`，`a.insert(1, 7)` 之後 a 是？
* [4, 7, 9, 2]
- [7, 4, 9, 2]
- [4, 9, 7, 2]
- [4, 7, 2]
E: insert(i, x) 把 x 放到索引 i 的位置，原本 i 以後的元素都往後移。

Q: `a = [1, 2, 3, 4]`，`x = a.pop(1)` 之後，x 與 a 分別是？
* 2 與 [1, 3, 4]
- 1 與 [2, 3, 4]
- 2 與 [1, 2, 3]
- 3 與 [1, 2, 4]
E: pop(i) 拿走並回傳索引 i 的元素，後面的往前補。
```

## 十一、常見錯誤

- **索引超出範圍**：長度 n 的串列，合法索引是 `0 ~ n-1`（或 `-n ~ -1`），`a[n]` 會 `IndexError`。
- **`a = a.sort()` 變成 None**：`sort()`、`append()`、`reverse()` 都回傳 None，不要拿來指派。
- **以為 `b = a` 是複製**：要用 `a[:]` 或 `a.copy()`。
- **邊走訪邊刪除**：`for x in a: a.remove(x)` 會跳過元素；要走訪副本 `for x in a[:]`，或另外建新串列收結果。
- **切片的尾端含不含**：`a[1:3]` 是索引 1、2 兩個，不含 3。
- **`[[0]*c]*r` 建二維串列**：三列共用同一份，要用生成式。
- **`for x in a: x *= 2` 改不了串列**：要用索引 `a[i] *= 2`。
