## 一、堆疊（Stack）：後進先出（LIFO）

像一疊盤子：**最後放上去的，最先被拿走**。只能從**頂端**放、從頂端拿。

| 操作 | 意思 | Python（用串列） |
|---|---|---|
| push | 放到頂端 | `s.append(x)` |
| pop | 拿走頂端並回傳 | `s.pop()` |
| top / peek | 看頂端，不拿走 | `s[-1]` |
| 是否為空 | | `len(s) == 0` 或 `not s` |

```python
s = []
s.append(1)        # push 1
s.append(2)        # push 2
s.append(3)        # push 3
print(s)           # [1, 2, 3]   最右邊是頂端
print(s.pop())     # 3           最後放的最先出來
print(s.pop())     # 2
print(s)           # [1]
print(s[-1])       # 1           看頂端
```

追蹤表：

| 動作 | 堆疊（左底、右頂） | 回傳 |
|---|---|---|
| push 1 | `[1]` | |
| push 2 | `[1, 2]` | |
| push 3 | `[1, 2, 3]` | |
| pop | `[1, 2]` | 3 |
| pop | `[1]` | 2 |

## 二、佇列（Queue）：先進先出（FIFO）

像排隊買票：**先排隊的先被服務**。從**後端**加入（enqueue）、從**前端**離開（dequeue）。

| 操作 | 意思 | Python（用 deque） |
|---|---|---|
| enqueue | 從後面加入 | `q.append(x)` |
| dequeue | 從前面拿走並回傳 | `q.popleft()` |
| front | 看最前面 | `q[0]` |

```python
from collections import deque
q = deque()
q.append(1)         # enqueue 1
q.append(2)         # enqueue 2
q.append(3)         # enqueue 3
print(list(q))      # [1, 2, 3]
print(q.popleft())  # 1      先進來的先出去
print(q.popleft())  # 2
print(list(q))      # [3]
```

追蹤表：

| 動作 | 佇列（左前、右後） | 回傳 |
|---|---|---|
| enqueue 1 | `[1]` | |
| enqueue 2 | `[1, 2]` | |
| enqueue 3 | `[1, 2, 3]` | |
| dequeue | `[2, 3]` | 1 |
| dequeue | `[3]` | 2 |

> 為什麼不用串列的 `pop(0)` 當佇列？它每次都要把後面所有元素往前搬，是 O(n)；`deque.popleft()` 是 O(1)。

## 三、堆疊 vs 佇列

| | 堆疊 Stack | 佇列 Queue |
|---|---|---|
| 規則 | 後進先出 LIFO | 先進先出 FIFO |
| 加入 | 頂端 | 後端 |
| 拿走 | 頂端 | 前端 |
| 生活例子 | 一疊盤子、瀏覽器「上一頁」 | 排隊、印表機工作序列 |
| 輸入 1、2、3，依序全拿出來 | 3、2、1 | 1、2、3 |

## 四、經典題：括號配對（用堆疊）

規則：遇到左括號就 push；遇到右括號，看頂端是不是對應的左括號，是就 pop，不是就不合法。掃完後堆疊要是空的。

```python
def balanced(text):
    s = []
    pair = {")": "(", "]": "[", "}": "{"}
    for ch in text:
        if ch in "([{":
            s.append(ch)
        elif ch in ")]}":
            if not s or s[-1] != pair[ch]:
                return False
            s.pop()
    return len(s) == 0

print(balanced("(a[b]c)"))   # True
print(balanced("(]"))        # False
print(balanced("(("))        # False   還有左括號沒配對
```

追蹤 `"([)]"`：

| 讀到 | 動作 | 堆疊 |
|---|---|---|
| `(` | push | `(` |
| `[` | push | `( [` |
| `)` | 頂端是 `[`，不是 `(` → 不合法 | |

結果 False。

## 五、經典題：用堆疊反轉

```python
s = []
for ch in "abc":
    s.append(ch)         # 依序放入 a b c
out = ""
while s:
    out += s.pop()       # 依序拿出 c b a
print(out)               # cba
```

## 六、遞迴與堆疊

遞迴的「呼叫堆疊」就是堆疊：最後呼叫的函式最先結束（LIFO），這也是為什麼遞迴太深會 `RecursionError`（堆疊疊太高）。見單元 12。

## 七、混合操作怎麼追蹤

題目常給一串動作，問最後內容：

```python
s = []
s.append(5)
s.append(8)
s.pop()
s.append(2)
s.append(9)
s.pop()
s.pop()
print(s)          # [5]
```

| 動作 | 堆疊 | 拿出 |
|---|---|---|
| push 5 | `[5]` | |
| push 8 | `[5, 8]` | |
| pop | `[5]` | 8 |
| push 2 | `[5, 2]` | |
| push 9 | `[5, 2, 9]` | |
| pop | `[5, 2]` | 9 |
| pop | `[5]` | 2 |

## 八、五分鐘小練習

```quiz
Q: 依序把 1、2、3 push 進堆疊後連續 pop 兩次，會依序拿到什麼？
* 3、2
- 1、2
- 2、3
- 3、1
E: 堆疊是後進先出，最後放的 3 先出來，接著是 2。

Q: 依序把 1、2、3 enqueue 進佇列後連續 dequeue 兩次，會依序拿到什麼？
* 1、2
- 3、2
- 2、3
- 3、1
E: 佇列是先進先出，先進去的先出來。

Q: Python 要實作佇列（FIFO），效率最好的做法是？
* `collections.deque` 搭配 `append` 與 `popleft`
- 串列的 `pop(0)`
- 串列的 `sort()`
- 字典
E: deque 兩端操作都是 O(1)；串列的 pop(0) 要搬動後面全部元素，是 O(n)。

Q: 括號匹配用堆疊，字串掃完後要「合法」的條件是？
* 堆疊是空的，而且過程中每個右括號都對得上頂端
- 堆疊裡還有元素
- 左右括號數量一樣即可
- 堆疊裡只剩一個左括號
E: 數量一樣不夠（例如 ")("），必須順序與種類都對得上；掃完還有左括號沒配對也不合法。

Q: 對空堆疊執行 `pop()` 會發生什麼事？
* IndexError（pop from empty list）
- 回傳 None
- 回傳 0
- 什麼都不發生
E: 空串列沒有東西可以拿，Python 會丟出 IndexError。使用前要先檢查是否為空。

Q: 動作序列：push 5、push 8、pop、push 2、push 9、pop、pop，最後堆疊內容是？
* [5]
- [5, 2]
- [5, 8]
- []
E: 追蹤：[5] → [5,8] → [5] → [5,2] → [5,2,9] → [5,2] → [5]。

Q: 下列哪一個是「堆疊」的特性？
* 後進先出
- 先進先出
- 隨機取出
- 只能從中間取
E: Stack = Last In, First Out。

Q: 遞迴函式的呼叫與返回順序，與哪一種資料結構的行為相同？
* 堆疊
- 佇列
- 二維陣列
- 字典
E: 最後被呼叫的函式最先結束，正是後進先出。
```

## 九、常見錯誤

- **混淆兩者方向**：堆疊從同一端進出；佇列是一端進、另一端出。
- **對空的堆疊／佇列取值**：`pop()`、`popleft()`、`s[-1]` 都會出錯，先檢查是否為空。
- **把串列的 `pop(0)` 當成堆疊的 pop**：堆疊 pop 是拿走**最後一個**。
- **括號配對只數數量**：必須順序與種類都對得上。
- **忘了 `from collections import deque`**。
