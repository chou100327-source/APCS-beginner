## 練習一：預測輸出（// 與 %）

先用「商 × 除數 + 餘數 = 被除數」驗算，再寫答案。

```python
print(17 // 5, 17 % 5)
print(-17 // 5, -17 % 5)
print(17 // -5, 17 % -5)
print(-17 // -5, -17 % -5)
print(7 / 2, 8 / 2)
print(int(-7 / 2), -7 // 2)
print(divmod(23, 4))
```

## 練習二：優先順序

請一步一步拆開算（照「單元 03」的拆解表），不要憑感覺。

```python
print(2 + 3 * 4 - 5)
print((2 + 3) * (4 - 5))
print(2 ** 3 ** 2)
print(-3 ** 2)
print(10 - 4 - 3)
print(100 / 10 / 5)
print(7 + 8 // 3 * 2 - 10 % 4)
print(2 * 3 ** 2 + 1)
```

## 練習三：變數追蹤表

畫一張 a、b、c 的追蹤表，一行一行往下記，最後寫出三個變數的值。

```python
a = 17
b = a % 5
c = a // 5
a = b * c
b = a % 4
c = c - a // 3
print(a, b, c)
```

## 練習四：數字拆解（追蹤表）

`n = 7305`。請畫出 while 迴圈每一輪的 n、digit、total，再寫輸出。

```python
n = 7305
total = 0
count = 0
while n > 0:
    digit = n % 10
    if digit != 0:
        total += digit
        count += 1
    n //= 10
print(total, count)
```

## 練習五：時間換算

輸入一個秒數，輸出「時:分:秒」（每個都補零成兩位）。例：輸入 3725 → `01:02:05`。先自己寫，下面是參考寫法。

```python
sec = 3725
h = sec // 3600
m = sec % 3600 // 60
s = sec % 60
print(f"{h:02d}:{m:02d}:{s:02d}")
```

## 五分鐘小測驗

```quiz
Q: `print(-17 // 5, -17 % 5)` 會輸出？
* -4 3
- -3 -2
- -3 2
- -4 -3
E: -17 ÷ 5 = -3.4，往負無窮捨去是 -4；餘數 = -17 - (-4)×5 = 3。

Q: `print(2 + 3 * 4 ** 2 // 6)` 的結果是？
* 10
- 14
- 26
- 8
E: 先 4**2=16，再由左往右 3*16=48，48//6=8，最後 2+8=10。

Q: 想把 `a` 的值往「後」繞一圈，大小為 7（0~6），最適合用哪個運算子？
* `%`
- `//`
- `**`
- `/`
E: 取餘數可以讓數字在 0 到 6 之間循環：`(a + d) % 7`。
```

## 今天的重點

- `//` 往負無窮捨去、`%` 的正負號跟除數相同；驗算用「商×除數+餘數=被除數」
- `**` 右結合，而且比負號先算：`-3 ** 2 = -9`
- 拆數字：`% 10` 取最右一位、`// 10` 去掉最右一位；`while n > 0` 一直剝
- 餘數的最大用途：讓數字在 0 ~ k-1 之間繞圈

## 練習一

```

-4 3
-4 -3
3 -2
3.5 4.0

(5, 3)
```

負數時：`//` 往負無窮捨去，餘數正負號跟除數相同。第 6 行 `int(-7 / 2)` 是 `-3`（往 0 捨去），`-7 // 2` 是 `-4`。

## 練習二

```
9
-5
512
-9
3
2.0
9
19
```

`2 ** 3 ** 2` 由右往左：先 `3 ** 2 = 9`，再 `2 ** 9 = 512`。`-3 ** 2` 先算次方再變負，是 `-9`。

## 練習三

```
6 2 1
```

追蹤：`a=17` → `b=2` → `c=3` → `a=2*3=6` → `b=6%4=2` → `c=3-6//3=3-2=1`。

## 練習四

```
15 3
```

一輪一輪剝：5 → 0（不算）→ 3 → 7，所以 total = 5+3+7 = 15，count = 3。

## 練習五

```
01:02:05
```

先 `// 3600` 得到小時，剩下的 `% 3600` 再 `// 60` 得到分，最後 `% 60` 是秒。
