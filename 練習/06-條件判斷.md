## 練習一：elif 的「符合就停」

分別把 `s` 換成 95、85、72、50 想一遍，寫出每次的輸出。注意這份程式的順序是「寫反」的。

```python
for s in [95, 85, 72, 50]:
    if s >= 60:
        print("D", end=" ")
    elif s >= 70:
        print("C", end=" ")
    elif s >= 80:
        print("B", end=" ")
    elif s >= 90:
        print("A", end=" ")
    else:
        print("E", end=" ")
print()
```

## 練習二：elif 與連續 if 的差別

對 n = 15 與 n = 4，兩個段落分別會印出什麼？

```python
for n in [15, 4]:
    # 段落 A
    if n % 3 == 0:
        print("Fizz", end=" ")
    elif n % 2 == 0:
        print("Even", end=" ")
    # 段落 B
    if n % 3 == 0:
        print("Fizz", end=" ")
    if n % 5 == 0:
        print("Buzz", end=" ")
    print("|")
```

## 練習四：巢狀條件

寫出輸入 (a, b) = (5, 3)、(5, 9)、(-2, 3)、(0, 0) 各自的輸出。

```python
for a, b in [(5, 3), (5, 9), (-2, 3), (0, 0)]:
    if a > 0:
        if b < a:
            print("X", end=" ")
        else:
            print("Y", end=" ")
    elif a < 0:
        print("Z", end=" ")
    else:
        print("W", end=" ")
print()
```

## 練習五：自己寫一個——閏年二月天數

輸入年份與月份，輸出那個月有幾天（閏年二月 29 天）。先自己寫，下面是參考寫法與檢查。

```python
def days(y, m):
    if m in (1, 3, 5, 7, 8, 10, 12):
        return 31
    elif m in (4, 6, 9, 11):
        return 30
    elif (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
        return 29
    else:
        return 28

print(days(2024, 2), days(2023, 2), days(1900, 2), days(2000, 2), days(2024, 4), days(2024, 12))
```

## 今天的重點

- `if / elif / else`：由上往下、符合就停；分段條件從最嚴格開始寫
- 連續的 `if` 是各自獨立判斷，可能全部成立
- 巢狀：先看外層，再看內層，一層一層往內走
- 多個可能值：`x in (1, 2, 3)`；範圍：`60 <= s < 70`
- 邊界：「以上」是 `>=`、「超過」是 `>`

## 練習三

```

```
