# 官方範例題（程式識讀・程式實作）

這兩份是 APCS 官方網站公布的**範例題本**，和正式考試的出題方式與格式最接近。建議在讀完單元 01 到 07、做完各單元練習之後再來做，當作最後的實戰演練。

> 這個網站不收錄官方題目的內容（版權屬於主辦單位），請直接用下面的連結開啟 PDF。

## 一、程式識讀（觀念題）範例 — Python 題本

<a href="https://apcs.csie.ntnu.edu.tw/wp-content/uploads/2025/09/%E7%A8%8B%E5%BC%8F%E8%AD%98%E8%AE%80_%E9%A1%8C%E7%9B%AE%E7%AF%84%E4%BE%8B_Python%E9%A1%8C%E6%9C%AC_0915.pdf" target="_blank" rel="noopener">開啟「程式識讀 題目範例（Python 題本）」PDF</a>

這是考試裡的「看程式回答問題」那一類：給你一段程式，問執行結果、某個變數的值、迴圈跑幾次、哪個敘述正確等。

**怎麼練：**

1. 先用紙筆作答，**不要先貼去執行**；看程式時畫追蹤表，一行一行記錄變數的值。
2. 做完再用「程式判題」分頁的「自訂輸入」把程式貼進去執行，對照自己的答案。
3. 答錯的題，回去翻對應的單元，並把原因寫進「速查・筆記」。

**可以回頭複習的單元（依題型）：**

| 題型 | 回去看 |
|---|---|
| 執行結果、變數的值 | 單元 02、03（追蹤表） |
| `//`、`%`、運算順序 | 單元 03 |
| `and` / `or` / `not`、短路求值 | 單元 04 |
| 二進位、`&` `|` `^` `<<` `>>` | 單元 05 |
| `if` / `elif` 走哪一條分支 | 單元 06 |
| 迴圈跑幾次、`break` / `continue` | 單元 07 |

## 二、程式實作（初級題本）範例

<a href="https://apcs.csie.ntnu.edu.tw/wp-content/uploads/2025/08/01_APCS-%E7%A8%8B%E5%BC%8F%E5%AF%A6%E4%BD%9C%E5%88%9D%E7%B4%9A%E9%A1%8C%E6%9C%AC%E7%AF%84%E4%BE%8B.pdf" target="_blank" rel="noopener">開啟「程式實作 初級題本範例」PDF</a>

這是考試裡「寫程式」的那一類：依題目敘述讀輸入、處理、再印出答案。

**怎麼練：**

1. 先讀題目，把「輸入格式」與「輸出格式」圈出來，並用範例輸入在紙上跑一遍。
2. 到「**程式判題**」分頁自己寫程式：在「自訂輸入」貼上題目的範例輸入，按「執行」，比對輸出是不是**逐字一樣**（空白、換行、小數位數都要對）。
3. 寫好後，自己多造幾組邊界測資再跑：只有 1 筆、數字很大、全部相同、剛好等於邊界值。
4. 卡超過 20 分鐘就先看一下相關單元，再回來寫。

**寫之前的提醒（也在考前檢查表裡）：**

- 只印答案本身，不要印「請輸入…」之類的提示文字。
- 一行多個數字用 `map(int, input().split())`，N 行資料用迴圈讀。
- 條件的順序、`range` 的邊界、累加器的初始值，是最常出錯的三個地方。
