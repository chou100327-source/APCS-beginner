## 練習一：二進位互轉（先手算再驗證）

手算下列轉換，再用 Python 驗證：20、45、100 轉二進位；`1011`、`11111`、`100000` 轉十進位。

```python
print(bin(20), bin(45), bin(100))
print(int("1011", 2), int("11111", 2), int("100000", 2))
print(format(5, "08b"))
print(0b101 + 0b11)
```

## 練習二：手算 &、|、^

先把兩數轉二進位、上下對齊，逐位算出再轉回十進位。

```python
a, b = 12, 10
print(a & b, a | b, a ^ b)
a, b = 25, 7
print(a & b, a | b, a ^ b)
a, b = 9, 9
print(a & b, a | b, a ^ b)
print(~0, ~9, ~-1)
```

## 練習三：位移

位移是乘除 2 的次方：左移 n 位 = 乘 2ⁿ，右移 n 位 = 除以 2ⁿ 捨去。

```python
print(3 << 2, 1 << 5, 6 << 0)
print(40 >> 1, 40 >> 3, 7 >> 1)
print((1 << 4) - 1)
print(1 << 10)
```

## 練習四：四個必考技巧

下面每一行分別在做什麼？先寫答案，再說出它「在判斷或計算什麼」。

```python
n = 12
print(n & 1)
print((n & 1) == 0)
print(n & (n - 1))
print(n & -n)
for m in [1, 6, 8, 100, 128]:
    print(m, m > 0 and (m & (m - 1)) == 0)
```

## 練習五：XOR 找落單與交換

追蹤 result 在每個 x 之後的值。再手動追蹤 a、b 交換。

```python
nums = [9, 4, 7, 4, 9]
result = 0
for x in nums:
    result ^= x
    print(result, end=" ")
print()
a, b = 6, 11
a ^= b
b ^= a
a ^= b
print(a, b)
```

## 練習六：開關追蹤

8 個開關從 0 開始，依序執行下面的操作，每步寫出 `flags` 的十進位值與二進位。

```python
flags = 0
flags |= 1 << 0
print(flags, format(flags, "08b"))
flags |= 1 << 3
print(flags, format(flags, "08b"))
flags ^= 1 << 0
print(flags, format(flags, "08b"))
flags ^= 1 << 5
print(flags, format(flags, "08b"))
flags &= ~(1 << 3)
print(flags, format(flags, "08b"))
print(bin(flags).count("1"))
```

## 五分鐘小測驗

```quiz
Q: 下列哪一個「不是」位元運算子？
* `and`
- `&`
- `^`
- `>>`
E: and 是邏輯運算子，對真假值運算；& ^ >> 才是位元運算子。

Q: `print(6 ^ 6)` 的結果是？
* 0
- 6
- 12
- 1
E: 相同的位元 XOR 之後都是 0，所以自己跟自己 XOR 一定是 0。

Q: `flags = 0b1010`，執行 `flags ^= 0b0110` 之後 flags 是？
* 0b1100（12）
- 0b1110（14）
- 0b0010（2）
- 0b0000（0）
E: 1010 ^ 0110 = 1100。XOR 對有 1 的位置做「切換」。
```

## 今天的重點

- 二進位位權：1、2、4、8、16、32、64、128
- `&` 都 1 才 1、`|` 有 1 就 1、`^` 不同才 1、`~x = -x-1`
- `<< n` 乘 2ⁿ、`>> n` 除以 2ⁿ 捨去
- 開：`|= 1<<k`、關：`&= ~(1<<k)`、切換：`^= 1<<k`、看：`(x >> k) & 1`
- XOR：`x^x=0`、`x^0=x`，找落單數與交換

## 練習一

```
0b10100 0b101101 0b1100100
11 31 32
00000101
8
```

十進位轉二進位：除以 2 取餘數、由下往上讀。二進位轉十進位：把有 1 的位置權重（1、2、4、8…）加起來。

## 練習二

```
8 14 6
1 31 30
9 9 0
-1 -10 0
```

`25 = 11001`、`7 = 00111`：AND = `00001` = 1、OR = `11111` = 31、XOR = `11110` = 30。自己跟自己：AND、OR 不變，XOR 是 0。`~x = -x - 1`。

## 練習三

```
12 32 6
20 5 3
15
1024
```

`(1 << 4) - 1 = 15 = 1111`：「低 4 位全是 1」的遮罩，常用來取出某個數的低 4 位。

## 練習四

```
0
True
8
4
1 True
6 False
8 True
100 False
128 True
```

`n & 1` 取最低位（奇偶）；`n & (n-1)` 把最低位的 1 清掉（結果為 0 就是 2 的次方）；`n & -n` 取出最低位的 1。

## 練習五

```
9 13 10 14 7 
11 6
```

成對的數會互相抵銷：9 出現兩次、4 出現兩次，剩下 7。三行 XOR 能交換 a、b，不需要暫存變數。

## 練習六

```
1 00000001
9 00001001
8 00001000
40 00101000
32 00100000
1
```

打開用 `|=`、切換用 `^=`、關閉用 `&= ~mask`。最後用 `bin(...).count("1")` 數有幾個開著。
