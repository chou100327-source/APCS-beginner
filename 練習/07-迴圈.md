## 練習一：range 與次數

先寫出每個迴圈印出的內容，再數它跑幾次。

```python
for i in range(4): print(i, end=" ")
print()
for i in range(3, 8): print(i, end=" ")
print()
for i in range(1, 10, 4): print(i, end=" ")
print()
for i in range(10, 2, -3): print(i, end=" ")
print()
for i in range(5, 5): print(i, end=" ")
print("完")
```

## 練習三：while 追蹤表

請畫一張 n、steps 的追蹤表（這是「Collatz 數列」）。

```python
n = 6
steps = 0
while n != 1:
    if n % 2 == 0:
        n //= 2
    else:
        n = 3 * n + 1
    steps += 1
    print(n, end=" ")
print()
print(steps)
```

## 練習四：break 與 continue

分別寫出兩個迴圈的輸出。

```python
for i in range(1, 15):
    if i % 4 == 0:
        break
    print(i, end=" ")
print()
for i in range(1, 15):
    if i % 4 == 0:
        continue
    if i > 10:
        break
    print(i, end=" ")
print()
```

## 練習五：雙層迴圈的次數

寫出 count 的值，並用「外層次數 × 內層次數」或逐列加總驗證。

```python
count = 0
for i in range(3):
    for j in range(4):
        count += 1
print(count)

count = 0
for i in range(1, 6):
    for j in range(i):
        count += 1
print(count)

count = 0
for i in range(1, 5):
    for j in range(i, 5):
        if (i + j) % 2 == 0:
            count += 1
print(count)
```

## 練習六：圖形題

先在紙上畫出輸出，再執行驗證。

```python
n = 4
for i in range(1, n + 1):
    print("*" * i)
print()
for i in range(n, 0, -1):
    print(" " * (n - i) + "*" * i)
print()
for i in range(1, n + 1):
    for j in range(1, i + 1):
        print(j, end="")
    print()
```

## 今天的重點

- `range(a, b)` 含頭不含尾，跑 `b - a` 次；跑 1~n 是 `range(1, n+1)`
- 累加器從 0 開始（放在迴圈外）、連乘從 1 開始
- `break` 結束整個迴圈、`continue` 只結束這一輪
- 雙層迴圈：總次數是外層 × 內層（內層若依外層變就逐列加）
- 追蹤題：畫表頭、一輪一列，別用心算跳步

## 練習一

```
0 1 2 3 
3 4 5 6 7 
1 5 9 
10 7 4 
完
```

含頭不含尾。`range(5, 5)` 一次都不跑。倒數時 step 為負，頭要比尾大。

## 練習二

```
55
25
47
```

最後一個用 3 的倍數與 5 的倍數合併計算，要注意 15 的倍數只算一次（`or` 本來就只算一次）。

## 練習三

```
3 10 5 16 8 4 2 1 
8
```

6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1，共 8 步。偶數就除以 2、奇數就乘 3 加 1。

## 練習四

```
1 2 3 
1 2 3 5 6 7 9 10 
```

`break` 整個結束、`continue` 只跳過本輪。第二個迴圈在 i = 11 時 break。

## 練習五

```
12
15
6
```

第 1 個：3×4 = 12。第 2 個：1+2+3+4+5 = 15。第 3 個要逐組檢查 (i, j)，(1,1)(1,3)(2,2)(2,4)(3,3)(4,4) 共 6 組。

## 練習六

```
*
**
***
****

****
 ***
  **
   *

1
12
123
1234
```

第一個靠左的三角形；第二個靠右的倒三角（前面補空白）；第三個每列印出 1 到 i。
