# 03 算術運算

算術運算是初級題本的核心考點。APCS 觀念題最常見的形式是**給一段運算式問結果**，或**給一小段程式問最後變數的值**。每個細節都可能是陷阱，所以這個單元請慢慢讀、動手算。

> **本單元學完你要能做到**
> 1. 正確算出七個算術運算子的結果，尤其是負數的 `//` 與 `%`
> 2. 依優先順序一步一步算出複雜運算式
> 3. 用 `//` 與 `%` 拆數字、做進位、做循環
> 4. 說出 `round()`、`int()`、`math.floor()`、`math.ceil()` 的差別

## 一、七個算術運算子

| 運算子 | 意義 | 範例（a=7, b=2） | 結果 | 結果型態 |
|---|---|---|---|---|
| `+` | 加 | `a + b` | `9` | int |
| `-` | 減 | `a - b` | `5` | int |
| `*` | 乘 | `a * b` | `14` | int |
| `/` | 除（真除法） | `a / b` | `3.5` | **float** |
| `//` | 整數除法（商） | `a // b` | `3` | int |
| `%` | 取餘數 | `a % b` | `1` | int |
| `**` | 次方 | `a ** b` | `49` | int |

```python
print(7 / 2)    # 3.5
print(6 / 2)    # 3.0  ← 就算整除也是小數
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 10)  # 1024
print(2 ** 0.5) # 1.4142135623730951  次方可以是小數（開根號）
print(2 ** -1)  # 0.5   負次方會變小數
```

### `//` 與 `%` 是一對：商與餘數

`a // b` 是「商」，`a % b` 是「餘數」，它們永遠滿足：

```
a = (a // b) * b + (a % b)
```

例：17 ÷ 5 → 商 3、餘 2，因為 17 = 3×5 + 2。

```python
print(divmod(17, 5))    # (3, 2)  一次拿到商與餘數
q, r = divmod(17, 5)    # q = 3, r = 2
```

## 二、最常考的陷阱：負數的 `//` 與 `%`

Python 的 `//` 是「**往負無窮方向捨去**」（floor），而且餘數的正負號**跟除數相同**。這和 C、Java（往 0 捨去）不同，考卷上最愛拿這個當誘答。

```python
print(-7 // 2)   # -4   （-3.5 往下捨去 → -4，不是 -3！）
print(-7 % 2)    #  1   （-7 = (-4)×2 + 1）
print(7 // -2)   # -4
print(7 % -2)    # -1   （除數是負的，餘數也是負的或 0）
print(-7 // -2)  #  3   （3.5 往下捨去 → 3）
print(-7 % -2)   # -1   （-7 = 3×(-2) + (-1)）
```

### 驗算口訣

不確定時，用「商×除數＋餘數＝被除數」驗算：

| 算式 | 商 | 餘數 | 驗算 |
|---|---|---|---|
| `-7 // 2` / `-7 % 2` | -4 | 1 | (-4)×2 + 1 = -7 ✔ |
| `7 // -2` / `7 % -2` | -4 | -1 | (-4)×(-2) + (-1) = 7 ✔ |
| `-7 // -2` / `-7 % -2` | 3 | -1 | 3×(-2) + (-1) = -7 ✔ |

### 對照：`int()` 與 `//` 對負數不一樣

```python
print(int(-7 / 2))   # -3   int() 往 0 捨去
print(-7 // 2)       # -4   // 往負無窮捨去
```

## 三、運算子優先順序

由高到低，同一層由左往右算（`**` 例外，由**右往左**）：

| 優先 | 運算子 |
|---|---|
| 1（最高） | `()` 括號 |
| 2 | `**` 次方 |
| 3 | `+x` `-x` 正負號 |
| 4 | `*` `/` `//` `%` |
| 5（最低） | `+` `-` |

```python
print(2 + 3 * 4)         # 14   先乘後加
print((2 + 3) * 4)       # 20   括號改變順序
print(2 + 3 * 4 ** 2)    # 50   4**2=16 → 3*16=48 → 2+48
print(2 ** 3 ** 2)       # 512  由右往左：3**2=9 → 2**9
print(-2 ** 2)           # -4   ** 比負號高：先算 2**2=4，再變負 ← 陷阱
print((-2) ** 2)         # 4
print(10 - 4 - 3)        # 3    由左往右：(10-4)-3
print(100 / 10 / 5)      # 2.0  (100/10)/5
print(7 + 8 // 3 * 2)    # 11   8//3=2 → 2*2=4 → 7+4
```

### 一步一步拆解長算式（考試時請照做）

算 `7 + 8 // 3 * 2 - 10 % 4`：

| 步驟 | 目前算式 | 做了什麼 |
|---|---|---|
| ① | `7 + 8 // 3 * 2 - 10 % 4` | 乘除同層，由左往右 |
| ② | `7 + 2 * 2 - 10 % 4` | `8 // 3 = 2` |
| ③ | `7 + 4 - 10 % 4` | `2 * 2 = 4` |
| ④ | `7 + 4 - 2` | `10 % 4 = 2` |
| ⑤ | `9` | 加減由左往右 |

## 四、複合指定運算子

「對變數自己做運算，再存回自己」的縮寫：

```python
x = 10
x += 3      # x = x + 3   → 13
x -= 5      # x = x - 5   → 8
x *= 2      # x = x * 2   → 16
x //= 3     # x = x // 3  → 5
x %= 3      # x = x % 3   → 2
x **= 4     # x = x ** 4  → 16
x /= 4      # x = x / 4   → 4.0   注意：變成 float 了
print(x)
```

> Python **沒有** `x++` 與 `x--`，要寫 `x += 1`。

## 五、常用數學函式

```python
print(abs(-7))            # 7       絕對值
print(max(3, 9, 5))       # 9
print(min(3, 9, 5))       # 3
print(sum([1, 2, 3, 4]))  # 10
print(pow(2, 10))         # 1024    等同 2 ** 10
print(round(3.456, 2))    # 3.46    四捨五入到小數第 2 位
print(round(3.7))         # 4

import math
print(math.sqrt(16))      # 4.0     平方根（結果是 float）
print(math.floor(3.7))    # 3       往下取整
print(math.floor(-3.2))   # -4
print(math.ceil(3.2))     # 4       往上取整
print(math.ceil(-3.7))    # -3
print(math.gcd(12, 18))   # 6       最大公因數
```

### 四種「變整數」方法比較

| 值 | `int(x)` | `round(x)` | `math.floor(x)` | `math.ceil(x)` |
|---|---|---|---|---|
| 3.7 | 3 | 4 | 3 | 4 |
| 3.2 | 3 | 3 | 3 | 4 |
| -3.7 | -3 | -4 | -4 | -3 |
| -3.2 | -3 | -3 | -4 | -3 |

### `round()` 的銀行家捨入

Python 的 `round()` 遇到「剛好 .5」時，會捨入到**最接近的偶數**：

```python
print(round(0.5))   # 0
print(round(1.5))   # 2
print(round(2.5))   # 2   ← 不是 3！
print(round(3.5))   # 4
```

想要「一般的四捨五入」（正數）：`int(x + 0.5)`。

## 六、經典應用 1：拆解數字的每一位

```python
n = 472
hundreds = n // 100          # 4
tens = (n // 10) % 10        # 7
ones = n % 10                # 2
print(hundreds, tens, ones)  # 4 7 2
```

為什麼 `(n // 10) % 10` 能取出十位？

| 步驟 | 運算 | 結果 | 意義 |
|---|---|---|---|
| ① | `472 // 10` | `47` | 把個位砍掉 |
| ② | `47 % 10` | `7` | 取最右邊一位（原本的十位） |

### 任意位數：用迴圈一位一位剝

```python
n = 9384
total = 0
while n > 0:
    digit = n % 10      # 取出最右邊一位
    total += digit
    n //= 10            # 去掉最右邊一位
print(total)            # 24
```

追蹤表：

| 輪次 | n（輪開始） | digit | total | n（輪結束） |
|---|---|---|---|---|
| 1 | 9384 | 4 | 4 | 938 |
| 2 | 938 | 8 | 12 | 93 |
| 3 | 93 | 3 | 15 | 9 |
| 4 | 9 | 9 | 24 | 0 |

迴圈結束（n = 0）。這個模板還能：反轉數字、數幾位數、判斷回文、檢查每位是否為奇數……

```python
# 反轉數字：1234 → 4321
n, rev = 1234, 0
while n > 0:
    rev = rev * 10 + n % 10
    n //= 10
print(rev)              # 4321
```

## 七、經典應用 2：時間與進位換算

```python
# 把 3725 秒換成「時:分:秒」
sec = 3725
h = sec // 3600           # 1
m = (sec % 3600) // 60    # 2
s = sec % 60              # 5
print(f"{h:02d}:{m:02d}:{s:02d}")   # 01:02:05
```

```python
# 找零錢：N 元用 500、100、50 的最少張數
n = 678
c500 = n // 500; n %= 500     # 1，剩 178
c100 = n // 100; n %= 100     # 1，剩 78
c50  = n // 50;  n %= 50      # 1，剩 28
print(c500, c100, c50, n)     # 1 1 1 28
```

> 一行寫兩個指令可以用分號 `;`，但題目裡通常分開寫比較不會出錯。

## 八、經典應用 3：循環與繞圈

餘數的最大用處：**讓數字在 0 ~ k-1 之間繞圈**。

```python
# 星期：今天星期三（用 3 表示，週日 0），100 天後是星期幾？
today = 3
print((today + 100) % 7)    # 4   （星期四）

# 時鐘：現在 10 點，過 5 小時是幾點？
print((10 + 5) % 12)        # 3

# 判斷倍數
print(15 % 5 == 0)          # True   15 是 5 的倍數
```

| 想知道什麼 | 寫法 |
|---|---|
| n 是不是偶數 | `n % 2 == 0` |
| n 是不是 k 的倍數 | `n % k == 0` |
| 往後繞 d 格（大小 k） | `(x + d) % k` |
| 往前繞 d 格（大小 k） | `(x - d) % k`（Python 負數餘數是非負的，很方便） |

## 九、小數誤差：為什麼 0.1 + 0.2 ≠ 0.3？

```python
print(0.1 + 0.2)           # 0.30000000000000004
print(0.1 + 0.2 == 0.3)    # False
print(abs(0.1 + 0.2 - 0.3) < 1e-9)   # True  用「差很小」代替「相等」
```

電腦用二進位存小數，有些十進位小數無法精確表示。能用整數就用整數（例如用「分」代替「元」）；非得比較小數時，用「差的絕對值小於一個很小的數」。

## 十、五分鐘小練習

```quiz
Q: `print(-7 // 2)` 會輸出什麼？
* -4
- -3
- 3
- 4
E: Python 的 // 是往負無窮方向捨去，-3.5 往下捨去就是 -4。這跟 C/Java 的「往 0 捨去」不同，是最常考的誘答。

Q: `print(2 ** 3 ** 2)` 會輸出什麼？
* 512
- 64
- 36
- 12
E: ** 是右結合（由右往左算），所以先算 3**2=9，再算 2**9=512。若是左結合才會是 (2**3)**2=64。

Q: `print(6 / 2)` 的輸出是？
* 3.0
- 3
- 2
- 3.5
E: 在 Python 3 裡 / 一律回傳浮點數，就算整除也會印出 3.0。要得到整數 3 要用 6 // 2。

Q: 想取出整數 n 的「十位數」，下列何者正確？
* `(n // 10) % 10`
- `n % 10`
- `n // 10`
- `n % 100`
E: 先 //10 把個位砍掉，再 %10 取出最右邊那位（原本的十位）。n % 10 拿到的是個位數。

Q: `print(-7 % 2)` 會輸出什麼？
* 1
- -1
- 0
- 3
E: Python 的餘數正負號跟除數相同。-7 = (-4)×2 + 1，所以餘數是 1。這跟 C 語言的 -7 % 2 = -1 不同。

Q: `print(7 + 8 // 3 * 2)` 的結果是？
* 11
- 17
- 9
- 13
E: // 與 * 同層由左往右：8//3=2，2*2=4，7+4=11。很多人會誤以為 8 // (3*2)。

Q: `print(round(2.5))` 的結果是？
* 2
- 3
- 2.5
- 2.0
E: Python 的 round() 對剛好 .5 採「銀行家捨入」，捨入到最近的偶數，所以 2.5 → 2、3.5 → 4。

Q: 今天是星期 5（週日=0 … 週六=6），過 10 天是星期幾？
* 星期 1
- 星期 0
- 星期 2
- 星期 3
E: (5 + 10) % 7 = 15 % 7 = 1。用 % 7 讓星期繞圈，是餘數運算最典型的應用。
```

## 十一、常見錯誤

- **忘了 `/` 一定回傳小數**：要索引串列、當 `range()` 的參數時，用 `/` 會噴 `TypeError`，該用 `//`。
- **負數取餘數想成 C 的行為**：Python 的 `-7 % 2` 是 `1`，不是 `-1`。
- **`**` 的結合方向記反**：`2 ** 3 ** 2` 是 512 不是 64。
- **`-2 ** 2` 以為是 4**：`**` 比負號先算，答案是 `-4`。
- **`round()` 當成一般四捨五入**：`round(2.5)` 是 2，不是 3。
- **`int()` 與 `//` 搞混**：對負數結果不同，`int(-3.5)` 是 -3，`-7 // 2` 是 -4。
- **用 `x++`**：Python 沒有，要寫 `x += 1`。
- **用 `==` 比較小數**：`0.1 + 0.2 == 0.3` 是 False。
