# 04 邏輯運算

邏輯運算處理的是「**真**」與「**假**」。程式要能「做決定」（單元 06 的 `if`、單元 07 的 `while`），都得先算出一個條件是真還是假。初級題本常把邏輯運算和條件判斷綁在一起考，重點是**能正確判斷一個複合條件的真假值**。

> **本單元學完你要能做到**
> 1. 用比較運算子寫出條件，並知道結果一定是 `True` / `False`
> 2. 默寫 `and`、`or`、`not` 真值表，並依優先順序算出複合條件
> 3. 利用短路求值避免錯誤，並預測哪一邊「不會被執行」
> 4. 用笛摩根定律改寫條件
> 5. 說出哪些值會被當成 `False`

---

## 一、布林值與比較運算子

比較的結果一定是布林值（`True` 或 `False`，**首字母大寫**）。

| 運算子 | 意義 | 範例 | 結果 |
|---|---|---|---|
| `==` | 等於 | `3 == 3` | `True` |
| `!=` | 不等於 | `3 != 5` | `True` |
| `>` | 大於 | `3 > 5` | `False` |
| `<` | 小於 | `3 < 5` | `True` |
| `>=` | 大於等於 | `5 >= 5` | `True` |
| `<=` | 小於等於 | `5 <= 3` | `False` |

```python
print(10 > 3)            # True
print(10 == 10.0)        # True    整數與浮點數值相同就相等
print("a" == "a")        # True
print("a" == "A")        # False   大小寫不同
print("apple" < "banana")# True    字串依字典順序比
print([1, 2] == [1, 2])  # True
```

> **`=` 與 `==` 完全不同**：`=` 是「指定」（把值放進變數），`==` 才是「比較」。除錯題最愛考。

---

## 二、三個邏輯運算子

| 運算子 | 中文 | 意思 |
|---|---|---|
| `and` | 且 | **兩邊都真**才真 |
| `or` | 或 | **至少一邊真**就真 |
| `not` | 非 | 真變假、假變真 |

```python
print(True and False)    # False
print(True or False)     # True
print(not True)          # False
```

### 真值表（一定要背熟）

| A | B | A and B | A or B | not A |
|---|---|---|---|---|
| True | True | True | True | False |
| True | False | False | True | False |
| False | True | False | True | True |
| False | False | False | False | True |

### 口訣

- **and：一假則假**（全真才真）
- **or：一真則真**（全假才假）

### 用生活語言對應

```python
age = 20
has_id = True
print(age >= 18 and has_id)      # True   成年「而且」有證件才能進場
print(age < 12 or age >= 65)     # False  兒童「或」長者才有優惠
print(not has_id)                # False  沒有證件嗎？不是
```

## 三、優先順序：`not` > `and` > `or`

比較運算子（`==`、`<` …）比 `not`/`and`/`or` **更高**。完整由高到低：

```
算術運算 (+ - * / ...)
比較運算 (== != < > <= >=)
not
and
or
```

```python
print(True or False and False)
# and 先算：False and False = False
# 再算 or：True or False = True    → True

print((True or False) and False)
# 括號先算：True or False = True
# True and False = False           → False

print(not True or True)
# not 先算：not True = False
# False or True = True             → True

print(1 + 1 == 2 and 3 > 2)        # True   算術 → 比較 → and
```

### 一步一步拆長條件

設 `a = 5, b = 0, c = 8`，算 `a > 3 or b > 0 and c < 5`：

| 步驟 | 算式 | 結果 |
|---|---|---|
| ① 比較先算 | `True or False and False` | |
| ② and 先於 or | `True or (False and False)` | |
| ③ | `True or False` | `True` |

> 不確定優先順序時，**直接加括號**。考場上括號不扣分，記錯才扣分。

## 四、短路求值（Short-circuit）

- `A and B`：A 是假 → 結果已經是假，**B 根本不會被執行**
- `A or B`：A 是真 → 結果已經是真，**B 根本不會被執行**

```python
x = 0
if x != 0 and 10 / x > 1:     # 左邊 False → 右邊不會算，不會除以零
    print("yes")
else:
    print("no")               # 輸出 no，程式不會當掉
```

如果寫反了：

```python
if 10 / x > 1 and x != 0:     # ← 先算 10/0 → ZeroDivisionError
    print("yes")
```

### 判斷「哪一邊有被執行」

```python
def say(msg):
    print(msg)
    return True

say("A") or say("B")     # 只印 A（A 已是 True，B 被跳過）
say("A") and say("B")    # 印 A、B（A 是 True，還要看 B）
```

> 短路求值最常用在：「**先確認安全，才去使用**」。例如 `i < len(a) and a[i] > 0`、`x != 0 and y / x > 1`。

---

## 五、`and` / `or` 的回傳值（進階但可能出現）

`and` 與 `or` 其實不一定回傳 `True`/`False`，而是回傳「**最後決定結果的那個值**」：

```python
print(0 or 5)        # 5      or：回傳第一個為真的，都假回傳最後一個
print(3 or 5)        # 3
print(0 or "")       # ""     全假 → 回傳最後一個
print(3 and 5)       # 5      and：全真回傳最後一個
print(0 and 5)       # 0      遇到假就回傳那個假
```

常見用法：`name = input() or "無名氏"`（輸入空字串就用預設值）。

## 六、笛摩根定律

```
not (A and B)  等價於  (not A) or  (not B)
not (A or  B)  等價於  (not A) and (not B)
```

**口訣**：把 `not` 分進去，**`and` 與 `or` 互換**，每個條件取反。

### 取反比較運算子

| 原條件 | 取反後 |
|---|---|
| `x > 5` | `x <= 5` |
| `x >= 5` | `x < 5` |
| `x == 5` | `x != 5` |

### 範例

「**不是**（成年 **且** 有票）」等價於「未成年 **或** 沒票」：

```python
adult, ticket = False, True
print(not (adult and ticket))          # True
print((not adult) or (not ticket))     # True   結果相同
```

例：把 `not (x > 3 and y <= 5)` 改寫：
- 分配 not：`(not x > 3) or (not y <= 5)`
- 取反比較：`x <= 3 or y > 5`

## 七、連鎖比較與成員判斷 `in`

```python
score = 85
print(60 <= score < 90)       # True   等同 60 <= score and score < 90
print(1 < 2 < 3)              # True
print(1 < 3 < 2)              # False

print(3 in [1, 2, 3])         # True   成員判斷
print('a' in "apple")         # True
print("ap" in "apple")        # True   子字串也可以
print(5 not in [1, 2, 3])     # True
```

## 八、哪些值會被當成「假」？

放進 `if`、`while`、`not` 時，下列值視為 `False`，**其餘全部為 `True`**：

| 假值 | 說明 |
|---|---|
| `False` | 布林假 |
| `0`、`0.0` | 數字零 |
| `""` | 空字串 |
| `[]` | 空串列 |
| `{}` | 空字典 |
| `None` | 什麼都沒有 |

```python
if []:
    print("有東西")
else:
    print("空的")          # ← 輸出這行

items = [3, 1, 2]
if items:                  # 比 len(items) > 0 更簡潔
    print("至少一筆")
```

### 陷阱

```python
print(bool("0"))      # True   字串 "0" 非空
print(bool(" "))      # True   一個空白也算有東西
print(bool([0]))      # True   串列裡有一個元素
print(bool(-1))       # True   負數也是 True
```

## 九、經典應用：閏年判斷

**規則**：西元年能被 4 整除**且**不能被 100 整除，**或**能被 400 整除。

```python
year = int(input())
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("閏年")
else:
    print("平年")
```

| 年份 | `%4==0` | `%100!=0` | `%400==0` | 結果 |
|---|---|---|---|---|
| 2024 | T | T | F | 閏年 |
| 2023 | F | — | F | 平年 |
| 1900 | T | F | F | 平年 |
| 2000 | T | F | T | 閏年 |

另一個經典：**判斷三角形**（任兩邊和大於第三邊）：

```python
a, b, c = map(int, input().split())
ok = a + b > c and a + c > b and b + c > a
print("可以" if ok else "不行")
```

## 十、五分鐘小練習

```quiz
Q: `print(True or False and False)` 會輸出什麼？
* True
- False
- 會噴錯
- None
E: and 的優先順序比 or 高，所以先算 False and False = False，再算 True or False = True。

Q: 依笛摩根定律，`not (A or B)` 等價於下列何者？
* `(not A) and (not B)`
- `(not A) or (not B)`
- `A and B`
- `not A or B`
E: ¬(A∨B) = ¬A∧¬B。口訣：把 not 分進去，and 與 or 要互換。

Q: `x = 0` 時，`if x != 0 and 10 / x > 1:` 為什麼不會發生除以零的錯誤？
* 因為短路求值：and 左邊已是 False，右邊不會被執行
- 因為 Python 允許除以零
- 因為 10 / 0 會回傳 0
- 其實會噴錯
E: and 只要左邊為假就直接得出 False，右邊整段跳過不執行。所以「先檢查再使用」的順序很重要，寫反了就會出錯。

Q: 下列哪個值放進 if 判斷時會被當成 False？
* `[]`（空串列）
- `[0]`
- `"0"`
- `-1`
E: 空串列、空字串、0、0.0、{}、None 都視為 False。注意 [0] 與 "0" 都「有東西」，所以是 True。

Q: `print(not 0 and 5)` 的輸出是？
* 5
- True
- False
- 0
E: not 0 是 True，再算 True and 5。and 在左邊為真時，回傳右邊的值 5。

Q: 下列哪個條件與 `not (a >= 10 or b < 5)` 等價？
* `a < 10 and b >= 5`
- `a < 10 or b >= 5`
- `a >= 10 and b < 5`
- `a <= 10 and b > 5`
E: 笛摩根：分配 not、and/or 互換，並把每個比較取反：a>=10 變 a<10，b<5 變 b>=5。注意 >= 的反面是 <，不是 <=。

Q: `print(1 < 3 < 2)` 的輸出是？
* False
- True
- 會噴錯
- 2
E: 連鎖比較等同 1 < 3 and 3 < 2，後半是假，所以整體 False。

Q: 判斷年份 y 是閏年，正確的條件是？
* `(y % 4 == 0 and y % 100 != 0) or y % 400 == 0`
- `y % 4 == 0 and y % 100 != 0 and y % 400 == 0`
- `y % 4 == 0 or y % 100 == 0`
- `y % 400 == 0 and y % 4 == 0`
E: 四年一閏，逢百不閏，逢四百又閏。所以是「整除 4 且不整除 100」或「整除 400」。
```

## 十一、常見錯誤

- **`=` 打成 `==`（或相反）**：在 `if` 裡寫 `if x = 5:` 直接語法錯誤；寫 `x == 5` 當指定則什麼都沒改變。
- **把 `and` / `or` 的優先順序記反**：`not` > `and` > `or`，不確定就加括號。
- **忘了 `True` / `False` 首字大寫**：Python 不是 `true` / `false`。
- **短路求值的順序寫反**：檢查條件（如 `x != 0`、`i < len(a)`）一定放在使用它的那一邊之前。
- **範圍判斷寫成 `x > 1 and < 10`**：右邊的 `< 10` 少了變數，要寫 `x > 1 and x < 10` 或 `1 < x < 10`。
- **`if x == 1 or 2:`**：這永遠是真（因為 `2` 是真值）。要寫 `x == 1 or x == 2`，或 `x in (1, 2)`。
- **笛摩根只取反一半**：`not (A and B)` 變成 `not A and not B` 是錯的，要是 `or`。
