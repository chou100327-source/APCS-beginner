# 07 迴圈

「**把同一件事做很多次**」就是迴圈。印 100 行、加總 1 到 N、一個一個檢查每個數字……沒有迴圈就寫不出像樣的程式。迴圈也是 APCS 觀念題「**追蹤程式執行結果**」考最多的主題，一定要練到能**手動模擬每一輪變數怎麼變化**。

> **本單元學完你要能做到**
> 1. 說出 `range()` 三種寫法會產生哪些數、迴圈跑幾次
> 2. 用 `for` 與 `while` 寫出累加、計數、找最大最小
> 3. 用追蹤表手算迴圈輸出
> 4. 使用 `break`、`continue`、`for…else`
> 5. 寫出雙層迴圈（九九乘法表、星星三角形），算出總執行次數

---

## 一、`for` 迴圈與 `range()`

`for` 迴圈用在「**知道要做幾次**」的時候。

```python
for i in range(5):
    print(i)
```

輸出 `0 1 2 3 4`（每個一行）。`i` 是迴圈變數，每跑一輪就換成下一個值。

### `range()` 的三種用法

| 寫法 | 產生的數 | 次數 |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 5 |
| `range(2, 6)` | 2, 3, 4, 5 | 4 |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 | 5 |
| `range(10, 0, -2)` | 10, 8, 6, 4, 2 | 5 |
| `range(5, 5)` | （空，一次都不跑） | 0 |
| `range(5, 2)` | （空，因為 step 預設 +1 且 5 > 2） | 0 |

```python
for i in range(5):           print(i, end=" ")   # 0 1 2 3 4
print()
for i in range(2, 6):        print(i, end=" ")   # 2 3 4 5
print()
for i in range(1, 10, 2):    print(i, end=" ")   # 1 3 5 7 9
print()
for i in range(10, 0, -2):   print(i, end=" ")   # 10 8 6 4 2
```

### 一定要記住

- `range(a, b)` **含頭不含尾**：包含 a、**不含** b，跑 `b - a` 次
- 要跑 1 到 n 就是 `range(1, n + 1)`（**多一個 +1**，最常忘）
- 倒數時 step 要是負的，而且「頭」要比「尾」大

## 二、累加與計數：迴圈的兩大模板

### 模板 1：累加（加總）

```python
total = 0                      # ① 先準備一個「累加器」，初始為 0
for i in range(1, 101):
    total += i                 # ② 每輪加進去
print(total)                   # 5050
```

追蹤表（只看前幾輪）：

| 輪 | i | total（輪結束） |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |
| … | … | … |
| 100 | 100 | 5050 |

### 模板 2：計數（滿足條件才 +1）

```python
count = 0
for i in range(1, 101):
    if i % 7 == 0:             # 是 7 的倍數
        count += 1
print(count)                   # 14
```

### 模板 3：找最大 / 最小（擂台法）

```python
n = int(input())
nums = list(map(int, input().split()))   # 例如 3 9 2 7
biggest = nums[0]                        # 先假設第一個最大
for x in nums:
    if x > biggest:
        biggest = x                      # 有人更大就換人
print(biggest)                           # 9
```

### 模板 4：連乘（階乘）

```python
n = 5
result = 1                     # 連乘的初始值是 1，不是 0！
for i in range(1, n + 1):
    result *= i
print(result)                  # 120
```

## 三、`while` 迴圈

`while` 用在「**不知道要做幾次，但知道什麼時候該停**」。

```python
n = 1
total = 0
while n <= 100:        # 條件為真就繼續
    total += n
    n += 1             # ← 一定要更新，否則無窮迴圈！
print(total)           # 5050
```

### while 的三要素

1. **初始化**：迴圈前先設好變數（`n = 1`）
2. **條件**：每輪開始前檢查（`n <= 100`）
3. **更新**：迴圈裡必須讓條件「有機會變假」（`n += 1`）

### 例：猜到幾次才停——求最大公因數（輾轉相除法）

```python
a, b = 48, 18
while b != 0:
    a, b = b, a % b
print(a)    # 6
```

追蹤表：

| 輪 | a | b | 說明 |
|---|---|---|---|
| 開始 | 48 | 18 | |
| 1 | 18 | 12 | a, b = 18, 48 % 18 |
| 2 | 12 | 6 | a, b = 12, 18 % 12 |
| 3 | 6 | 0 | a, b = 6, 12 % 6 |
| 結束 | 6 | 0 | b == 0 → 答案是 a = 6 |

### 例：數字有幾位數

```python
n = 12345
digits = 0
while n > 0:
    n //= 10
    digits += 1
print(digits)   # 5
```

### for 與 while 怎麼選？

| 情況 | 選擇 |
|---|---|
| 要跑固定 N 次、或走訪一整串資料 | `for` |
| 不知道跑幾次，看條件決定 | `while` |
| 拆數字每一位 | `while n > 0` |
| 「做到…為止」 | `while` |

## 四、`break` 與 `continue`

| 關鍵字 | 作用 |
|---|---|
| `break` | **整個迴圈立刻結束**，跳到迴圈後面的程式 |
| `continue` | **只結束這一輪**，直接進入下一輪 |

```python
for i in range(1, 20):
    if i % 7 == 0:
        break          # 遇到第一個 7 的倍數就整個跳出
    if i % 2 == 0:
        continue       # 遇到偶數，跳過這輪剩下的程式
    print(i, end=" ")
# 輸出：1 3 5
```

追蹤表：

| i | `i % 7 == 0`? | `i % 2 == 0`? | 動作 |
|---|---|---|---|
| 1 | 否 | 否 | 印 1 |
| 2 | 否 | 是 | continue（不印） |
| 3 | 否 | 否 | 印 3 |
| 4 | 否 | 是 | continue |
| 5 | 否 | 否 | 印 5 |
| 6 | 否 | 是 | continue |
| 7 | **是** | — | **break**，迴圈結束 |

### 經典：判斷質數

```python
n = int(input())
is_prime = n >= 2
for d in range(2, int(n ** 0.5) + 1):   # 只需檢查到 √n
    if n % d == 0:
        is_prime = False
        break                           # 找到因數就不用再找了
print("質數" if is_prime else "不是質數")
```

## 五、`for … else`

迴圈「**正常跑完（沒有被 break）**」才會執行 `else` 區塊。常用於「找遍了都沒找到」。

```python
target = 99
nums = [3, 5, 7, 9]
for x in nums:
    if x == target:
        print("找到了")
        break
else:
    print("沒找到")   # 迴圈跑完沒 break → 執行這行
```

| 情況 | 是否執行 else |
|---|---|
| 迴圈正常結束 | ✔ 執行 |
| 被 `break` 中斷 | ✘ 不執行 |
| `for` 一次都沒跑（空範圍） | ✔ 執行 |

## 六、巢狀迴圈（雙層迴圈）

迴圈裡面再放迴圈：**外層跑一次，內層就從頭跑完一整輪**。

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()                   # 內層跑完，換行
```

輸出：

```
1*1=1  1*2=2  1*3=3
2*1=2  2*2=4  2*3=6
3*1=3  3*2=6  3*3=9
```

### 總次數 = 外層次數 × 內層次數

外層 3 次 × 內層 3 次 = 9 次。

### 圖形題：星星三角形

```python
n = 4
for i in range(1, n + 1):
    print("*" * i)
```

```
*
**
***
****
```

倒三角、金字塔：

```python
n = 4
for i in range(n, 0, -1):          # 倒三角
    print("*" * i)

for i in range(1, n + 1):          # 置中金字塔
    print(" " * (n - i) + "*" * (2 * i - 1))
```

```
****
***
**
*
   *
  ***
 *****
*******
```

### 內層次數依外層而變

```python
count = 0
for i in range(1, 5):          # i = 1..4
    for j in range(i):         # j 跑 i 次
        count += 1
print(count)                   # 1+2+3+4 = 10
```

| i | 內層次數 | 累計 count |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |

### 巢狀迴圈裡的 `break`

`break` 只會跳出**最內層**的那個迴圈，外層照跑：

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break           # 只結束內層
        print(i, j)
# 輸出 (0,0) (1,0) (2,0)
```

## 七、迴圈追蹤的方法（考試必練）

**手動模擬**是這個單元最重要的技能。步驟：

1. 列出所有變數，寫成表頭
2. 迴圈每跑一輪，寫一列
3. 注意「輪開始」與「輪結束」的值，以及 `if` 有沒有成立

**例題**：

```python
a = 1
b = 0
while a < 20:
    if a % 3 == 0:
        b += a
    a += 2
print(a, b)
```

| 輪 | a（開始） | `a < 20`? | `a % 3 == 0`? | b | a（結束） |
|---|---|---|---|---|---|
| 1 | 1 | 是 | 否 | 0 | 3 |
| 2 | 3 | 是 | **是** | 3 | 5 |
| 3 | 5 | 是 | 否 | 3 | 7 |
| 4 | 7 | 是 | 否 | 3 | 9 |
| 5 | 9 | 是 | **是** | 12 | 11 |
| 6 | 11 | 是 | 否 | 12 | 13 |
| 7 | 13 | 是 | 否 | 12 | 15 |
| 8 | 15 | 是 | **是** | 27 | 17 |
| 9 | 17 | 是 | 否 | 27 | 19 |
| 10 | 19 | 是 | 否 | 27 | 21 |
| 結束 | 21 | **否** | | | |

輸出 `21 27`。

## 八、五分鐘小練習

```quiz
Q: `for i in range(2, 6)` 這個迴圈會跑幾次？
* 4 次
- 5 次
- 6 次
- 3 次
E: range(a, b) 含頭不含尾，會跑 b - a 次，也就是 i = 2,3,4,5 共 4 次。

Q: 下面這段會印出什麼？`for i in range(1, 6):` / `  if i % 2 == 0: continue` / `  print(i, end="")`
* 135
- 246
- 12345
- 1
E: continue 是「跳過本輪剩下的程式，直接進下一輪」，所以偶數都被跳過，只印出奇數 1、3、5。break 才是整個跳出迴圈。

Q: for...else 的 else 區塊在什麼時候會執行？
* 迴圈正常跑完、中途沒有被 break 時
- 迴圈一次都沒跑時
- 迴圈被 break 中斷時
- 每一輪迴圈結束時
E: 這是 Python 特有語法，常拿來做「找遍了都沒找到」的處理；只要中途 break 過，else 就不會執行。

Q: 外層 `for i in range(3)` 裡面再放內層 `for j in range(4)`，內層的程式總共執行幾次？
* 12 次
- 7 次
- 4 次
- 3 次
E: 3 × 4 = 12 次。雙層迴圈的總次數是相乘，這也是 O(n²) 複雜度的由來。[[viz:complexity]]

Q: `total = 0`、`for i in range(1, 6): total += i`，結束後 total 是多少？
* 15
- 10
- 21
- 5
E: range(1, 6) 是 1,2,3,4,5，加總 = 15。注意 6 不含在內；若要含 6 需寫 range(1, 7)。

Q: `for i in range(10, 0, -3): print(i, end=" ")` 會印出什麼？
* 10 7 4 1
- 10 7 4 1 0
- 10 8 6 4 2
- 9 6 3
E: 從 10 開始每次減 3：10、7、4、1，下一個是 -2，已經小於等於終點 0，所以停止。終點 0 不包含。

Q: 下列迴圈會印出幾個星號？`for i in range(3):` / `  for j in range(i):` / `    print("*", end="")`
* 3 個
- 6 個
- 9 個
- 0 個
E: i=0 時內層跑 0 次、i=1 跑 1 次、i=2 跑 2 次，共 0+1+2 = 3 次。

Q: 下列哪段程式會變成「無窮迴圈」？
* `n = 1` / `while n < 10:` / `    print(n)`
- `n = 1` / `while n < 10:` / `    n += 1`
- `for i in range(10): print(i)`
- `n = 10` / `while n > 0:` / `    n -= 3`
E: 第一段在迴圈裡沒有更新 n，條件 n < 10 永遠成立。其他三個都會讓條件在有限輪之後變假。
```

## 九、常見錯誤

- **`range` 的邊界少一或多一**（off-by-one）：要跑 1~n 是 `range(1, n + 1)`，不是 `range(1, n)`。
- **`while` 忘了更新變數**：`while n <= 100:` 裡忘了寫 `n += 1` 就會無窮迴圈（測試機會超時）。
- **累加器的初始值放在迴圈裡**：`total = 0` 如果寫在 `for` 裡面，每輪都會被歸零，最後只剩最後一輪的值。
- **連乘的初始值寫成 0**：`result = 0` 之後乘什麼都是 0，連乘要從 1 開始。
- **在迴圈裡改動正在走訪的 list**：邊走訪邊 `remove()` 會跳過元素，要改成走訪副本或用新 list 收結果。
- **內外層迴圈變數同名**：外層用 `i`、內層也用 `i` 會互相覆蓋，內層請改用 `j`。
- **`break` 以為會跳出所有迴圈**：它只會結束最內層那一個。
- **`continue` 放在更新變數之前**：`while` 裡若 `continue` 在 `n += 1` 之前，會永遠卡住。

```python
# 危險寫法：n 為偶數時 continue 跳過了 n += 1，卡死在原地
n = 0
while n < 10:
    if n % 2 == 0:
        continue
    n += 1
```
