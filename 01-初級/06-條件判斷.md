# 06 條件判斷

到目前為止，程式都是「從上到下一行一行照跑」。條件判斷讓程式能「**看情況做不同的事**」：成績幾分以上及格、輸入是正是負、年份是不是閏年……這是所有程式邏輯的骨幹。

Python 用**縮排**（通常 4 個空白）表示「這幾行屬於同一個區塊」，不用大括號。縮排錯了會直接語法錯誤或邏輯跑掉，這是初學者最常出錯的地方。

> **本單元學完你要能做到**
> 1. 寫出 `if`、`if-else`、`if-elif-else` 並說出執行流程
> 2. 設計「條件順序」，避開分段判斷的陷阱
> 3. 使用巢狀條件與邏輯運算子簡化條件
> 4. 手動追蹤「經過哪些分支」
> 5. 看範例寫出完整的判斷程式（等第、閏年、三角形、比大小…）

---

## 一、最簡單的 `if`

```python
n = int(input())
if n > 0:
    print("正數")
print("結束")
```

- 條件成立（`n > 0` 為 `True`）→ 執行縮排的那幾行
- 不成立 → 直接跳過，往下執行縮排**以外**的程式

| 輸入 n | 輸出 |
|---|---|
| 5 | 正數<br>結束 |
| -3 | 結束 |

**三個重點**：條件後面要有冒號 `:`；要執行的行要縮排；縮排以外的行不受 `if` 影響（上面的「結束」一律會印）。

---

## 二、`if - else`：二選一

```python
n = int(input())
if n % 2 == 0:
    print("偶數")
else:
    print("奇數")
```

`else` **沒有條件**，意思是「剛才的條件不成立時」，兩個區塊**一定會執行其中一個**。

---

## 三、`if - elif - else`：多選一

```python
score = 76
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"
print(grade)   # C
```

**執行流程**（由上而下、符合就停）：

| 檢查 | `76 >= 90`? | `76 >= 80`? | `76 >= 70`? | → |
|---|---|---|---|---|
| 結果 | 否 | 否 | **是** | 執行 `grade = "C"`，**後面全部跳過** |

### 為什麼「順序」這麼重要

如果把順序反過來：

```python
score = 95
if score >= 60:
    grade = "D"        # ← 95 一進來就被這裡抓走
elif score >= 70:
    grade = "C"
elif score >= 80:
    grade = "B"
elif score >= 90:
    grade = "A"
print(grade)           # D    ← 錯了！
```

> **規則**：分段判斷一定要「**從最嚴格（最大）的條件開始寫**」，或者每個條件都用範圍框住（例如 `60 <= s < 70`）。

### `elif` 與連續 `if` 的差別

```python
n = 15
# 寫法 A：elif —— 擇一
if n % 3 == 0:
    print("Fizz")
elif n % 5 == 0:
    print("Buzz")
# 只印 Fizz

# 寫法 B：連續 if —— 每個都檢查一遍
if n % 3 == 0:
    print("Fizz")
if n % 5 == 0:
    print("Buzz")
# 印 Fizz 再印 Buzz（15 兩個條件都成立）
```

| 寫法 | 特性 |
|---|---|
| `if / elif / else` | 一整組只會**執行一個**區塊 |
| 一串 `if` | 每個條件**各自獨立**判斷，可能執行多個 |

## 四、巢狀條件

`if` 裡面可以再放 `if`：

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入場")
    else:
        print("沒有票")
else:
    print("未成年")
```

用 `and` 合併後（只要「可入場」的情況）更簡潔：

```python
if age >= 18 and has_ticket:
    print("可以入場")
```

### 巢狀的縮排層級

每多一層，多縮排 4 個空白：

```python
x = 5
if x > 0:                  # 第 0 層
    print("正")             # 第 1 層（4 空白）
    if x > 3:              # 第 1 層
        print("大於3")      # 第 2 層（8 空白）
print("結束")               # 回到第 0 層
```

## 五、經典：比大小（找最大值）

```python
a, b, c = map(int, input().split())

# 寫法 1：用 if-elif
if a >= b and a >= c:
    m = a
elif b >= a and b >= c:
    m = b
else:
    m = c
print(m)

# 寫法 2：擂台法（逐一挑戰）
m = a
if b > m:
    m = b
if c > m:
    m = c
print(m)

# 寫法 3：直接用內建函式
print(max(a, b, c))
```

「擂台法」是之後迴圈找最大值的雛形：先假設第一個最大，其他的依序挑戰。

## 六、經典：三角形分類

三邊長 a、b、c，先判斷能不能構成三角形（任兩邊和大於第三邊），再分類。

```python
a, b, c = map(int, input().split())
if a + b <= c or a + c <= b or b + c <= a:
    print("不是三角形")
elif a == b == c:
    print("正三角形")
elif a == b or b == c or a == c:
    print("等腰三角形")
elif a * a + b * b == c * c or a * a + c * c == b * b or b * b + c * c == a * a:
    print("直角三角形")
else:
    print("一般三角形")
```

注意**順序**：「正三角形」必須排在「等腰」前面，因為正三角形也滿足「兩邊相等」。

| 輸入 | 輸出 |
|---|---|
| `3 4 5` | 直角三角形 |
| `5 5 5` | 正三角形 |
| `5 5 8` | 等腰三角形 |
| `1 2 3` | 不是三角形 |

## 七、三元運算式（一行寫完 if-else）

```python
n = 5
result = "偶數" if n % 2 == 0 else "奇數"
print(result)    # 奇數
```

格式：`值1 if 條件 else 值2`——條件成立取值 1，否則取值 2。

```python
print("及格" if score >= 60 else "不及格")
bigger = a if a > b else b           # 等同 max(a, b)
absval = x if x >= 0 else -x         # 等同 abs(x)
```

> 簡單的二選一用三元式，三種以上或要執行多行時，還是用 `if/elif/else`。

## 八、條件判斷常用的寫法整理

| 想判斷 | 寫法 |
|---|---|
| 範圍 | `60 <= s < 70` |
| 多個可能值 | `x in (1, 2, 3)` 或 `x in [1, 2, 3]` |
| 是否為空 | `if not s:` / `if s == "":` |
| 是否為偶數 | `n % 2 == 0` |
| 是否為某數倍數 | `n % k == 0` |
| 都不是 | `x not in (1, 2, 3)` |
| 兩個條件都要 | `a and b` |
| 其一即可 | `a or b` |

## 九、追蹤程式經過哪些分支

觀念題常見：「輸入 X 時，下列程式輸出什麼？」做法：**用輸入值一個條件一個條件檢查**。

```python
x = int(input())
y = 0
if x > 10:
    y += 1
if x > 5:
    y += 2
elif x > 0:
    y += 3
else:
    y += 4
print(y)
```

| 輸入 x | `x > 10` | y 變成 | `x > 5` | `x > 0` | y 最終 |
|---|---|---|---|---|---|
| 12 | 是 | 1 | 是 | （跳過） | 1 + 2 = **3** |
| 7 | 否 | 0 | 是 | （跳過） | 0 + 2 = **2** |
| 3 | 否 | 0 | 否 | 是 | 0 + 3 = **3** |
| -1 | 否 | 0 | 否 | 否 → else | 0 + 4 = **4** |

注意第一個 `if` 與後面的 `if/elif/else` 是**兩組獨立**的判斷。

## 十、完整範例：計程車費

**題目**：起跳 1.5 公里內 85 元。超過的部分，每 0.5 公里（不足 0.5 以 0.5 計）加 5 元。輸入公里數（可有小數），輸出車資。

```python
import math
km = float(input())
if km <= 1.5:
    fare = 85
else:
    units = math.ceil((km - 1.5) / 0.5)   # 超過的部分有幾個 0.5 公里（無條件進位）
    fare = 85 + units * 5
print(fare)
```

驗算：`km = 2.2` → 超過 0.7 → `0.7 / 0.5 = 1.4` → 進位 2 個單位 → `85 + 10 = 95`。

- 大括號 {}
- begin / end
- 分號 ;

Q: `result = "偶數" if n % 2 == 0 else "奇數"`，當 n = 7 時 result 是？
* 奇數
- 偶數
- True
- 會噴錯

- A 印 2 行、B 印 2 行
- A 印 1 行、B 印 1 行
- A 印 2 行、B 印 1 行
E: elif 是同一組擇一，15 符合第一個條件就不再看第二個；連續兩個 if 是各自獨立的判斷，15 同時是 3 與 5 的倍數，兩個都印。

* 2
- 3
- 5
- 6
E: 第一組 if（x>10）不成立，y 維持 0；第二組 if/elif/else 中 x>5 成立，y 加 2 後停止，y = 2。

Q: 判斷三角形種類時，下列哪一個順序「不會」出錯？
* 先判斷是否為正三角形，再判斷等腰
- 先判斷等腰，再判斷正三角形
- 先判斷直角，再判斷是否能構成三角形
- 順序都沒有差別
E: 正三角形也滿足「兩邊相等」，如果等腰寫在前面，正三角形會被它攔走。條件要由特殊（嚴格）到一般。

- `if x in (1, 2, 3):`
- `if x == 1 or x == 2 or x == 3:`

## 十二、常見錯誤

- **縮排混用 Tab 與空白**：看起來一樣但 Python 會噴 `TabError`，整份程式只用空白（4 格）最安全。
- **縮排層級不一致**：同一區塊裡有的行 4 個空白、有的 3 個，會 `IndentationError`。
- **忘記冒號**：`if x > 0` 少了結尾的 `:` 會語法錯誤。`else`、`elif` 也一樣。
- **分段條件順序寫反**：判斷等第、級距時，一定要從最大（最嚴格）的條件開始往下寫。
- **`elif` 寫成連續的 `if`**：連續 `if` 是「每個都檢查一遍」，可能同時成立執行多次；`elif` 才是「擇一」。
- **`else` 後面加條件**：`else x > 0:` 是語法錯誤；要加條件請用 `elif`。
- **邊界值不清楚**：`>` 與 `>=` 差一個等號就差一個分數；題目寫「以上」是 `>=`、「超過」是 `>`。
- **用 `=` 代替 `==`**：`if x = 5:` 語法錯誤。
