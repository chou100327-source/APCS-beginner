# 01 輸入與輸出

APCS 的實作題是「**電腦自動判題**」：你的程式從鍵盤（標準輸入）拿資料，把答案印到螢幕（標準輸出），判題系統再**逐字比對**你的輸出和標準答案。所以只要多一個空白、少一個換行、多印一句「請輸入…」，整題就是 0 分。

這個單元是所有單元的地基：不管後面學什麼，每一題你都得先把資料讀進來、再把答案印出去。

> **本單元學完你要能做到**
> 1. 不看資料，寫出讀取「一個數字」「一行文字」「一行多個數字」「N 行資料」的程式
> 2. 說得出 `print` 的 `sep`、`end` 各自改變什麼
> 3. 用 f-string 控制小數位數、補零、對齊
> 4. 看範例輸入輸出，一次就把格式寫對

---

## 一、先搞懂：資料是怎麼進來的

判題系統會把測資「餵」給你的程式，就好像有人在鍵盤上打字一樣。`input()` 每呼叫一次，就從輸入裡**拿走一整行**（到換行符號為止）。

假設測資長這樣：

```
3
10 20 30
Alice
```

| 你寫的程式 | 讀到的內容 | 型態 |
|---|---|---|
| 第 1 次 `input()` | `"3"` | 字串 |
| 第 2 次 `input()` | `"10 20 30"` | 字串（整行，包含空白） |
| 第 3 次 `input()` | `"Alice"` | 字串 |

兩個關鍵事實：

1. **一次一行**：`input()` 不會多拿，也不會少拿。第幾行就要第幾次呼叫。
2. **永遠是字串**：就算你看到的是 `3`，Python 拿到的也是 `"3"`（長度為 1 的字串），不是數字 3。

## 二、讀輸入的五種基本寫法

### 寫法 1：讀一行文字

```python
name = input()
print("Hello,", name)
```

輸入 `Alice` → 輸出 `Hello, Alice`。

### 寫法 2：讀一個整數 / 一個小數

```python
n = int(input())       # 輸入 5     → n 是整數 5
x = float(input())     # 輸入 3.14  → x 是小數 3.14
print(n + 1)           # 6
print(x * 2)           # 6.28
```

`int(input())` 其實是兩件事疊在一起：先 `input()` 拿到字串 `"5"`，再 `int()` 把字串變成整數 `5`。

### 寫法 3：一行有「固定幾個」數字

```python
# 輸入：3 5 7
a, b, c = map(int, input().split())
print(a + b + c)       # 15
```

把它拆開看，一步一步發生什麼事：

| 步驟 | 程式 | 結果 |
|---|---|---|
| ① | `input()` | `"3 5 7"` |
| ② | `.split()` | `["3", "5", "7"]`（依空白切開成串列） |
| ③ | `map(int, …)` | 把串列裡每個字串都套用 `int` → 3、5、7 |
| ④ | `a, b, c = …` | 依序指派給 a、b、c |

> `.split()` **不寫括號內容**時，會自動依「任意數量的空白」切開，連多個空白、頭尾空白都會處理。

### 寫法 4：一行有「不確定幾個」數字

```python
# 輸入：4 8 15 16 23 42
nums = list(map(int, input().split()))
print(nums)            # [4, 8, 15, 16, 23, 42]
print(len(nums))       # 6
print(sum(nums))       # 108
```

一次把整行丟進串列（list），之後用 `len()` 知道有幾個、用 `sum()` 加總。

### 寫法 5：先給 N，再給 N 行資料

最常見的格式：第一行是 N，接下來 N 行各有一個數字。

```python
# 輸入：
# 3
# 90
# 85
# 77
n = int(input())
total = 0
for _ in range(n):         # 重複 n 次；_ 表示「這個變數我用不到」
    score = int(input())
    total += score
print(total)               # 252
```

同一件事，也可以用「串列生成式」一行完成：

```python
n = int(input())
scores = [int(input()) for _ in range(n)]   # 讀 n 行，每行轉成整數
print(sum(scores))
```

另一種常見格式：第一行 N，**第二行**有 N 個數字（全部在同一行）：

```python
n = int(input())
nums = list(map(int, input().split()))
```

> **判斷用哪種寫法**：看範例輸入。數字在同一行 → `split()`；數字各佔一行 → 迴圈呼叫 `input()`。

## 三、`print()` 的完整用法

### 3-1 基本

```python
print("APCS")          # APCS
print(123)             # 123       數字會自動轉成文字
print(3 + 4)           # 7         先算再印
print("3 + 4")         # 3 + 4     加了引號就是文字
print()                # （印一個空行）
```

### 3-2 一次印多個東西：預設用空白隔開

```python
print("A", "B", "C")        # A B C
print("分數：", 95)          # 分數： 95
print(1, 2, 3)              # 1 2 3
```

### 3-3 `sep`：改「中間」的分隔

```python
print("A", "B", "C", sep="-")      # A-B-C
print(2026, 11, 1, sep="/")        # 2026/11/1
print("A", "B", "C", sep="")       # ABC   （完全不隔開）
print("A", "B", "C", sep="\n")     # A 換行 B 換行 C （每個一行）
```

### 3-4 `end`：改「結尾」，預設是換行

```python
print("Hello", end=" ")
print("APCS")               # Hello APCS   （兩個 print 接在同一行）

print("1", end="")
print("2", end="")
print("3")                  # 123
```

### 3-5 兩個一起用

```python
print(1, 2, 3, sep=", ", end="!\n")    # 1, 2, 3!
```

`\n` 是「換行字元」，`\t` 是「Tab」。字串裡要放這些特殊字元就用反斜線開頭。

### 3-6 把串列「展開」印出

```python
nums = [5, 8, 2]
print(nums)                 # [5, 8, 2]     ← 連中括號都印出來了，通常不是你要的
print(*nums)                # 5 8 2         ← * 把串列拆成一個一個東西
print(*nums, sep=",")       # 5,8,2
print(" ".join(map(str, nums)))   # 5 8 2   ← 另一種，要先 map(str, …) 轉成字串
```

> APCS 輸出多個數字時，題目通常要求「以空白隔開」，`print(*nums)` 是最快的寫法。

## 四、格式化字串（f-string）

在字串前面加一個 `f`，大括號 `{}` 裡面就可以放變數或算式，Python 會把結果塞進去。

```python
name = "小明"
score = 87.5
print(f"{name} 的分數是 {score}")        # 小明 的分數是 87.5
print(f"兩倍是 {score * 2}")              # 兩倍是 175.0
```

在大括號裡用冒號 `:` 再加上「格式說明」，就能控制外觀：

| 寫法 | 意思 | 範例（值） | 結果 |
|---|---|---|---|
| `{x:.2f}` | 小數點後 2 位（四捨五入） | `x = 3.14159` | `3.14` |
| `{x:.0f}` | 不要小數 | `x = 2.7` | `3` |
| `{n:03d}` | 整數，不足 3 位補 0 | `n = 7` | `007` |
| `{n:5d}` | 整數，佔 5 格，靠右 | `n = 42` | `   42` |
| `{n:<5d}` | 佔 5 格，靠左 | `n = 42` | `42   ` |
| `{x:8.2f}` | 總寬 8、小數 2 位 | `x = 3.14159` | `    3.14` |
| `{n:,}` | 千分位逗號 | `n = 1234567` | `1,234,567` |
| `{r:.1%}` | 百分比 | `r = 0.256` | `25.6%` |

```python
h, m = 9, 5
print(f"{h:02d}:{m:02d}")    # 09:05      時間格式常用
avg = 252 / 3
print(f"{avg:.2f}")          # 84.00
```

### 沒有 f-string 的舊寫法（看得懂就好）

```python
print("%.2f" % 3.14159)          # 3.14
print("{:.2f}".format(3.14159))  # 3.14
```

## 五、不知道有幾筆資料時怎麼讀？

有些題目不會告訴你有幾行，只說「輸入到檔案結束為止」。這時要「一直讀，直到沒有東西可讀」：

```python
import sys

for line in sys.stdin:          # 一行一行讀，讀完自動停
    line = line.strip()         # 去掉行尾換行與頭尾空白
    if line == "":              # 遇到空行就略過
        continue
    print("讀到：", line)
```

另一種等價的寫法（用例外處理）：

```python
while True:
    try:
        line = input()
    except EOFError:            # 沒有資料可讀時，input() 會丟出這個錯誤
        break
    print("讀到：", line)
```

> 初級題絕大多數都會先給 N，用不到這招；但看懂它能讓你在考場不慌。

## 六、完整範例：從題目到程式

**題目**：輸入三個整數代表三科成績，輸出總分與平均（平均取到小數點後 1 位）。

```
輸入：
80 91 77
輸出：
248
82.7
```

**拆解思路**：

1. 一行三個整數 → 寫法 3。
2. 總分 = 三個相加。
3. 平均 = 總分 / 3，用 `{avg:.1f}` 取一位小數。
4. 只印答案：兩行，不要加「總分：」。

```python
a, b, c = map(int, input().split())
total = a + b + c
avg = total / 3
print(total)
print(f"{avg:.1f}")
```

**驗算**：248 ÷ 3 = 82.666… 四捨五入到一位 = 82.7 ✔。

## 七、五分鐘小練習

```quiz
Q: `input()` 讀進來的資料型態永遠是什麼？
* 字串 str
- 整數 int
- 依內容自動判斷
- 浮點數 float
E: input() 一律回傳字串，要做數學運算前必須自己用 int() 或 float() 轉型。

Q: 輸入一行是 `3 5 7`，想一次拿到三個整數，下列何者正確？
* `a, b, c = map(int, input().split())`
- `a, b, c = input()`
- `a, b, c = int(input())`
- `a, b, c = input().split(int)`
E: 先 .split() 依空白切成三個字串，再用 map(int, ...) 把每個都轉成整數，最後同時指派給三個變數。

Q: `print(f"{3.14159:.2f}")` 會輸出什麼？
* 3.14
- 3.142
- 3.14159
- 3
E: `:.2f` 代表取到小數第 2 位（會四捨五入）。`:03d` 則是補零到 3 位整數。

Q: `print("A", "B", sep="-", end="!")` 之後再執行 `print("C")`，螢幕上看到什麼？
* A-B!C
- A-B! C
- A B!C
- A-B! 之後 C 另起一行
E: sep 改 A 與 B 中間的分隔、end 把結尾從換行改成 "!"，所以下一個 print 的 C 直接接在同一行後面。

Q: `nums = [5, 8, 2]`，`print(*nums)` 會輸出什麼？
* 5 8 2
- [5, 8, 2]
- 582
- 5, 8, 2
E: 星號會把串列拆成一個一個獨立的值傳給 print，再用預設的空白隔開。直接 print(nums) 才會連中括號一起印。

Q: 輸入第一行是 `4`，第二行是 `1 2 3 4`。哪一段程式能正確算出總和？
* `n = int(input())` 然後 `print(sum(map(int, input().split())))`
- `n = int(input())` 然後 `print(sum(input()))`
- `n = int(input())` 然後 `print(sum(input().split()))`
- `n = input()` 然後 `print(n + n)`
E: sum() 需要數字，所以要先 split() 切開再用 map(int, …) 轉成整數。直接對字串或字串串列做 sum 都會 TypeError。
```

## 八、常見錯誤

- **忘記轉型**：`n = input()` 之後直接 `n + 1` 會噴 `TypeError`，字串不能跟整數相加。
- **字串相加的陷阱**：`input()` 讀兩個 `"3"` 與 `"4"` 直接相加得到 `"34"`，不是 7。
- **多印提示文字**：`print("請輸入 N：")` 在 APCS 會被當成輸出的一部分而判錯，**只印答案本身**。
- **輸出格式沒對齊題目**：該換行沒換行、多一個空白、小數位數不對，都會 WA（答案錯誤）。送出前一定拿範例輸入跑一遍，逐字比對範例輸出。
- **`.split()` 漏寫**：`map(int, input())` 會把整行字串的每個「字元」都拿去轉，空白轉不了直接錯。
- **行數對不上**：題目數字在同一行，你卻用了 N 次 `input()`，會 `EOFError`；反過來則只讀到第一個數字。
- **輸出尾巴多空白**：用 `end=" "` 印完整串數字，最後會多一個空白。用 `print(*nums)` 就不會。
