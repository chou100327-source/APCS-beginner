# 02 資料型態與變數

程式的本質就是「**把資料放進盒子，再對盒子裡的資料做事**」。這個盒子叫**變數**，盒子裡裝的東西有不同的**型態**。觀念題最愛考「這個運算的結果是什麼型態」「這行會不會出錯」，所以你要能一眼看出每個值的型態。

> **本單元學完你要能做到**
> 1. 說出 Python 的五種基本型態，並用 `type()` 驗證
> 2. 正確使用 `int()`、`float()`、`str()`、`bool()` 做型別轉換，並知道哪些會出錯
> 3. 追蹤一段變數指派的程式，寫出每一步變數的值
> 4. 避開變數命名的雷

## 一、變數是什麼？

```python
age = 17
```

這一行的意思是：「**建立一個叫 `age` 的盒子，把 17 放進去**」。`=` 不是數學的「等於」，而是「**把右邊的值存進左邊的變數**」，所以叫**指定（指派）運算子**。

```python
x = 5
y = x          # y 拿到 x 目前的值 5
x = 10         # x 改成 10，y 不受影響
print(x, y)    # 10 5
```

### 追蹤表：把變數的變化畫出來

考試最常見的題型：給你一小段程式，問最後某個變數是多少。方法是畫「追蹤表」，**一行一行**記錄所有變數：

```python
a = 3
b = 4
a = a + b      # 第 3 行
b = a - b      # 第 4 行
a = a - b      # 第 5 行
```

| 執行完 | a | b | 說明 |
|---|---|---|---|
| 第 1 行 | 3 | — | |
| 第 2 行 | 3 | 4 | |
| 第 3 行 | 7 | 4 | a = 3 + 4 |
| 第 4 行 | 7 | 3 | b = 7 − 4 |
| 第 5 行 | 4 | 3 | a = 7 − 3 |

最後 `a = 4, b = 3` —— 這就是「不用暫存變數交換兩個數」的算術版本。

> **關鍵**：`a = a + b` 先算右邊（用舊的 a 與 b），算完才存回 a。所以右邊的 `a` 是**舊值**。

## 二、五個基本型態

| 型態 | 中文 | 說明 | 範例 |
|---|---|---|---|
| `int` | 整數 | 沒有小數點；Python 的整數**沒有大小上限** | `10`、`-3`、`0` |
| `float` | 浮點數 | 有小數點的數 | `3.14`、`-0.5`、`2.0` |
| `str` | 字串 | 用單引號或雙引號包起來的文字 | `"APCS"`、`'7'` |
| `bool` | 布林 | 只有 `True` 與 `False` 兩個值（首字大寫） | `True` |
| `list` | 串列 | 一串有順序的資料，可以修改 | `[1, 2, 3]` |

```python
a = 7
b = 7.0
c = "7"
d = True
e = [7, 7.0, "7"]

print(type(a))   # <class 'int'>
print(type(b))   # <class 'float'>
print(type(c))   # <class 'str'>
print(type(d))   # <class 'bool'>
print(type(e))   # <class 'list'>
```

雖然 `a`、`b`、`c` 看起來都是「七」，但它們是三種不同的東西：

```python
print(a == b)    # True    7 與 7.0 數值相同
print(a == c)    # False   整數 7 與字串 "7" 不相等
print(a + b)     # 14.0    整數 + 浮點 = 浮點
print(c + c)     # 77      字串 + 字串 = 接在一起（字串串接）
print(c * 3)     # 777     字串 * 整數 = 重複
```

### 型態怎麼「混合」？

| 運算 | 結果型態 | 範例 |
|---|---|---|
| `int` ± `int` | `int` | `3 + 4` → `7` |
| `int` ± `float` | `float` | `3 + 4.0` → `7.0` |
| `int` `/` `int` | `float`（一律） | `6 / 2` → `3.0` |
| `int` `//` `int` | `int` | `6 // 2` → `3` |
| `float` `//` 任何 | `float` | `7.0 // 2` → `3.0` |
| `str` + `str` | `str` | `"a" + "b"` → `"ab"` |
| `str` + `int` | **錯誤 TypeError** | `"a" + 1` |

## 三、型別轉換

### 3-1 轉成整數 `int()`

```python
print(int("123"))     # 123    純數字字串可以轉
print(int(7.9))       # 7      小數 → 無條件捨去小數部分
print(int(-7.9))      # -7     往 0 的方向捨去（不是 -8）
print(int(True))      # 1      True 是 1，False 是 0
print(int("  42  "))  # 42     頭尾空白會被自動忽略
```

**會出錯的：**

```python
int("3.5")     # ValueError！字串裡有小數點，int 不吃
int("abc")     # ValueError
int("")        # ValueError  空字串
```

想把 `"3.5"` 變整數，要「先轉小數再轉整數」：`int(float("3.5"))` → `3`。

### 3-2 轉成浮點數 `float()`

```python
print(float("3.5"))   # 3.5
print(float(7))       # 7.0
print(float("10"))    # 10.0
```

### 3-3 轉成字串 `str()`

```python
print(str(456))        # "456"
print(str(3.0))        # "3.0"
print(str(456) + "1")  # "4561"   轉成字串後就是「接起來」
print(len(str(2026)))  # 4        算一個整數有幾位數：先轉字串再量長度
```

### 3-4 轉成布林 `bool()`

只有「空」和「零」是 `False`，其他全是 `True`：

```python
print(bool(0))        # False
print(bool(0.0))      # False
print(bool(""))       # False   空字串
print(bool([]))       # False   空串列
print(bool(None))     # False
print(bool(1))        # True
print(bool(-5))       # True    負數也是 True
print(bool("0"))      # True    ← 陷阱！字串 "0" 有一個字元，不是空的
print(bool("False"))  # True    ← 陷阱！非空字串
print(bool([0]))      # True    串列裡有一個元素
```

### 3-5 轉換總整理

| 轉換 | 成功例 | 失敗例 |
|---|---|---|
| `int()` | `int("12")`、`int(3.9)` | `int("3.9")`、`int("a")` |
| `float()` | `float("3.9")`、`float(2)` | `float("a")` |
| `str()` | 什麼都能轉 | — |
| `bool()` | 什麼都能轉 | — |

> **`int()` 不是四捨五入！** 它只是把小數點後面砍掉。要四捨五入用 `round()`（見單元 03 的坑）。

## 四、多重指派與交換

```python
x, y = 1, 2           # 同時指派：x = 1, y = 2
a = b = c = 0         # 三個都設成 0

x, y = y, x           # 交換！Python 專屬的簡潔寫法
print(x, y)           # 2 1
```

為什麼 `x, y = y, x` 不會把值蓋掉？因為 Python 會**先把右邊整包算好**（暫存成 `(2, 1)`），再一次存進左邊。

## 五、變數命名規則

**一定要遵守（否則語法錯誤）：**

- 只能用英文字母、數字、底線 `_`
- **不能以數字開頭**：`2nd` ✘、`second` ✔
- **不能有空白或符號**：`my score` ✘、`my_score` ✔
- **不能是保留字**：`if`、`for`、`while`、`class`、`True`… ✘
- **大小寫不同**：`Score` 與 `score` 是兩個不同的變數

**強烈建議：**

- 取有意義的名字：`total`、`count`、`max_score`
- 全大寫表示常數：`PI = 3.14159`
- **別用內建函式的名字**：`list`、`str`、`sum`、`max`、`min`、`input`、`id` 都不要拿來當變數名

```python
sum = 0                    # 看似沒事…
sum = sum + 5
# 之後你想用 sum([1, 2, 3]) 時 → TypeError: 'int' object is not callable
```

## 七、五分鐘小練習

```quiz
Q: `print(int(-3.7))` 會輸出什麼？
* -3
- -4
- 3
- 4
E: int() 是往 0 的方向捨去（truncate），所以 -3.7 變成 -3。要往下取整要用 math.floor()，那才會得到 -4。

Q: 下列哪一行會直接噴錯？
* `int("3.5")`
- `float("3.5")`
- `int(3.5)`
- `str(3.5)`
E: int() 不接受帶小數點的字串，必須先 float("3.5") 轉成 3.5 再 int() 變成 3。

Q: `x, y = 1, 2` 之後執行 `x, y = y, x`，x 與 y 分別是？
* x=2, y=1
- x=1, y=2
- x=2, y=2
- 會噴錯
E: Python 右邊會先整包算好 (2, 1) 再一次指派回左邊，所以能直接交換，不需要暫存變數。

Q: `print("3" + "4")` 與 `print(3 + 4)` 的輸出分別是？
* 34 和 7
- 7 和 7
- 34 和 34
- 7 和 34
E: 字串的 + 是「接起來」，整數的 + 才是加法。這是觀念題很愛考的誘答。

Q: `print(bool("0"))` 的輸出是？
* True
- False
- 0
- 會噴錯
E: bool() 只看「是不是空的」。字串 "0" 有一個字元，不是空字串，所以是 True。只有數字 0（整數 0 或 0.0）才是 False。

Q: 下列哪個「不能」當作變數名稱？
* `2nd_place`
- `_temp`
- `score2`
- `Total`
E: 變數名稱不能以數字開頭。底線開頭可以，名稱中間或結尾放數字也可以，大小寫字母都可以。

Q: 執行 `a = 5`、`b = a`、`a = a + 10` 之後，b 是多少？
* 5
- 15
- 10
- 不一定
E: b = a 當下複製了 a 的值 5。之後 a 改成 15，b 不會跟著變。數值型態的指派是「複製值」。
```

## 八、常見錯誤

- **把 `int()` 當四捨五入用**：`int(2.9)` 是 2。要四捨五入請用 `round()`，但它也有「銀行家捨入」的坑（見單元 03）。
- **字串數字直接相加**：`"3" + "4"` 得到 `"34"` 不是 `7`，這是觀念題最愛的誘答。
- **字串與整數混用**：`"成績" + 90` 會 TypeError。要寫 `"成績" + str(90)`，或用 `print("成績", 90)`。
- **用 `list`、`str`、`sum` 當變數名**：之後就不能再呼叫同名內建函式了。
- **`int("3.5")` 以為會得到 3**：直接噴 ValueError，要先 `float()`。
- **把 `bool("False")` 當成 False**：非空字串一律為 True。
- **`=` 與 `==` 搞混**：`=` 是指定、`==` 是比較（單元 04 詳述）。
